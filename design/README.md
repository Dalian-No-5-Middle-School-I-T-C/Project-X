## 方案速览（30 秒版）

- **为什么重构**：现状是 7011 行手写 CSS，存在双源令牌漂移、58 处从未定义的幽灵变量、25+ 硬编码色、emoji 与 lucide 图标混用——美学无单一事实源，"串台"已是既成事实。
- **美学方向「明澈 Clarity」**：内容即界面、品牌红克制到 ≤2%、效率即美学、一致即信任、状态可感知。Linear 的精确 × Apple 的克制 × 中文教育工具的亲和。
- **技术路线**：Tailwind CSS v4（`@theme` 令牌即主题）+ shadcn/ui（Radix 原语，组件源码自有）+ TanStack Table + lucide-react + chart.js 保留。原子化样式从结构上消灭类名冲突（防串台）。
- **功能守恒**：路由、权限、API、WorkspaceContext 一律不动；迁移 = 换皮。扫描识别主链路为最高优先级，网阅等低频路径克制投入。
- **可复现**：令牌唯一事实源（tokens.css → @theme → theme.ts 脚本同步）；新增颜色/组件必须走 DESIGN-SYSTEM §3.4 的三步规约，后期更新不会走样。

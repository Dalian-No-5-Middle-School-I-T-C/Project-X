# Project-X 完整代码审查 — 总结

## 项目概况
答题卡设计阅卷系统 (answer-card-designer v1.9.4)，全栈 TypeScript：
- **前端**: Vite + React 19 + React Router v7 + Chart.js
- **后端**: Express 5 + SQLite/MariaDB 双方言 + better-sqlite3
- **双构建**: web（教师/学生）和 scanner（Electron 桌面端）
- **AI**: Python LLM 微服务 (llmclient/)
- **原生**: C++ OpenCV 识别 + TWAIN 扫描仪桥接

## 已读完的关键文件

### 数据库 (6 文件)
- `schema.sql` — 30+ 张表，5 大模块（用户权限、答题卡设计、考试扫描、TWAIN、成绩统计、导出/AI/阅卷）
- `migrations.ts` — v1-v26 迁移链
- `mysql.ts` — DbAdapter 接口 + SqliteAdapter/MariadbAdapter
- `index.ts` — DB 初始化、bcrypt、默认管理员 bootstrap

### 后端核心 (20+ 文件)
- **中间件**: `auth.ts` (token 提取/验证/RBAC/强制改密)、`middleware.ts` (makeGate/getVisibleExamIds/requireExamAccess/validateExamIdsAccess)
- **权限**: `permissions.ts` (9 权限域、3 角色、3 教师子角色、通配符)
- **服务**: AuthService (login/logout/token 持久化 8h/180d)、ReviewService (阅卷提交/CAS 并发控制/争议检测)、ReviewAssignmentService (随机分配/工作量均衡)、BlockGradingConfigService (默认模板继承)、AssignedScoreService (赋分公式)
- **仓库**: UserRepository (含批量导入/CSV 解析)、ExamRepository (含 SSE 扫描进度)
- **路由**: auth(4)、users(10)、scores(9)、review(5)、block-grading-config(4)、exam-groups(10) 等共 24 个路由文件

### 前端组件 (60+ 文件)
- **入口**: main.tsx (BrowserRouter) / main-scanner.tsx (直连)
- **App.tsx** — 约 2400 行，30+ useState，统一状态机
- **WorkspaceContext** — ~80 个共享状态属性
- **模式路由**: home/design/exam-manage/analysis/scores/account 等 10 个模式
- **页面**: DesignPage + DesignEditors(1481行)、ExamManagePage
- **核心组件**: ScorePad(双模式打分键盘)、GradePanel(在线阅卷)、OnlineReviewPanel(网阅面板)、ScoreFixPage(改分/改答案)、AnalysisDistribution(箱线图)、ScannerPanel(扫描仪 8 状态机)、ScoreDetailPage(分析详情 4 子标签)
- **UI 库**: Button/Input/Modal/Panel/SegmentedControl/Spinner/LoadingScreen/Table

### 共享层
- `shared/types.ts` — 1200+ 行类型定义
- `shared/grading.ts` — 客观题/复合题批改逻辑
- `shared/layout.ts` — 答题卡排版引擎
- `shared/appVariant.ts` — student/teacher/teacher-scanner 三变体

### 其他模块
- `electron/main.cjs` — Electron 主进程
- `llmclient/` — Python Flask (OpenAI/DeepSeek/Gemini)
- `native/` — C++ (OpenCV 识别 + TWAIN 扫描)
- `miniprogram/` — 微信小程序

## 关键架构模式
1. **三层**: Routes → Services → Repositories
2. **双方言 DB**: 统一 DbAdapter 接口
3. **RBAC**: 角色-权限-通配符 + 教师可见范围
4. **Express 5 asyncHandler**: 防未捕获 Promise 挂起
5. **单文件 CSS**: ~6700 行，CSS 自定义属性主题切换

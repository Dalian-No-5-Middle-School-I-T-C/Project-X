# 演示数据（测试数据集）说明

> **适用版本**: v1.9.4 ~ v2.0.0（覆盖文理分科 #212、填空题升级 #211、网阅打分 #173/#177、P/D 统计口径 #206、考试模式切换 #178 等）
> **适用对象**: 教师、管理员、开发者 / 测试
> **关联文档**: [`testdata/demo-exams/README.md`](../testdata/demo-exams/README.md) · [`manifest.json`](../testdata/demo-exams/manifest.json) · [`DATABASE.md`](./DATABASE.md) · [`ARCHITECTURE.md`](./ARCHITECTURE.md)

项目内置一套「演示-」前缀的测试数据集，覆盖答题卡设计、网阅打分、成绩分析与大考合集等主要功能，导入后即可按场景演示或回归测试。数据以「演示-」为前缀并打 `is_demo=1` 归属标记，**不会触碰任何真实数据**，可随时一键清除。

## 2. 新功能覆盖说明

### 2.1 文理分科（#212）

- 16 名学生按班级分科：演示1班 = 理科（`track='science'`）、演示2班 = 文科（`track='arts'`）。
- 大考合集成员 `exam_group_members.track_type`：语文/数学/英语=`common`（共同科目）、物理/化学/生物=`science`、历史=`arts`。
- **效果**：大考分析页按科类筛选学生 —— 物理/化学/生物仅统计理科 8 人，历史仅统计文科 8 人；P/D 指标按参与学生计算。
- 第25周考试包保持全部 `common`，不受文理分科影响。
- 注意：文理分科仅作用于大考合集统计；单科周考覆盖 16 名学生（化学、生物各有 1 人缺考），化学缺考周杰（20260108）、生物缺考沈婷（20260116）为常规缺考测试点，与科类无关。

### 2.2 填空题升级（#211）

演示-语文卡（88000001）含「填空题（演示）」块（`subjective_blocks.block_kind='fill_blank'`），3 道题：

| 题目 | 演示点 |
|------|--------|
| Q1 | 两空，逐空自定义横线宽度/高度不同（`blanks_items_json`，如 20mm vs 34mm）+ 右侧批注「填＞或＜」+ 文字注释 |
| Q2 | 插入居中图片（资源 `data/answer-card/assets/88000001/fig-demo.png`，经 `/api/assets/88000001/fig-demo.png` 读取） |
| Q3 | 普通横线 + 文字注释（对照） |

在「答题卡设计」打开演示-语文即可看到；PDF 预览与导出均会渲染横线、注释与图片。

### 2.3 网阅打分按钮与步进（#173/#177/#212）

演示-网阅测试（卡 88000999）已配置两种打分模式：

- **题块 A**（满分 15·含 0.5）：`block_total` + `proportional`，`has_half_point=1` → 打分面板出现 0.5 步进按钮；**双评 2P**（`review_mode=2`）。
- **题块 B**（满分 25）：`per_question` + `equal`，`has_half_point=0` → 逐题位值打分。

### 2.4 网阅打分记录 / 双评仲裁 / 断点续批

- 题块 A 8 份卷：**3 份双评一致已批**（`status='reviewed'`、两轮 `score_breakdown`、`final_score`）、**1 份争议卷**（教师1 打 9 分 / 教师2 打 13 分，差 4 > 阈值 2 → `status='disputed'`，无最终分，可演示仲裁/复评流程）、**4 份已评 1 轮**（`pending`，等待第二评）。
- 题块 B 8 份卷：**3 份已批**、**5 份待批**（`ready`）。
- 已批卷逐题主观分已落 `question_scores`（`score_type='subjective'`、`manually_modified=1`），`student_scores` 已同步：张明 30 / 李华 34 / 王芳 29。
- **断点续批**：demo-teacher 在题块 B 留有草稿会话（`review_sessions.draft_scores`），打开面板可恢复位置与草稿分数。
- 批注：题块 B 已批卷上留有 1 条文字批注（`review_annotations`）。

### 2.5 P/D 统计口径与正态性检验（#206）

该功能**无新增数据字段**，指标实时计算：

- 难度 P = 均分 / 满分（保留 1 位小数）；区分度 D = 各题 D（27% 极端组法）算术平均。
- 正态性检验（Shapiro-Francia 主判 + KS Lilliefors 修正）在分析接口中计算。
- 查看路径：分析 → 单科/大考 → 概况，P/D 徽章与正态性结论；样本 < 4 人时 D 显示「样本不足」。
- 演示数据 16 人/科类 8 人，足以呈现完整统计。

### 2.6 每周考试审计（周报）

- **数据**：9 场 `exam_mode='quiz'` 晨测，日期按导入时动态生成（`getWeekWindow`），任何时刻导入都落在周报近 5 周窗口内：
  - 上上周 3 场（数学/英语/物理，周一~周三，得分率偏高）→ 已发布报告；
  - 上周 5 场（语文/数学/英语/物理/化学，周一~周五，数学刻意偏低）→ 已发布报告，并对上上周形成「较上周下降」对比；
  - 本周 1 场「演示-晨测数学(待出分)」未出分 → 周六发布时刻前展示「报告顺延」状态。
- **自动发布**：导入演示数据时服务端自动触发 `publishDueWeeks`（与生产定时任务同一逻辑），上周/上上周报告立即可见，无需等待周六定时器。
- **周组**：周报按 `source='week'` 自动建组（名称「第N周晨测包」，不含「演示-」前缀）；组内全为演示考试时，清除演示数据会一并删除该组。
- **查看路径**：首页 → 每周考试审计（近 5 周选项、年级切换、班级对比、薄弱题 Top5、较上周变化、AI 教学建议）。

## 3. 导入 / 清除 / 校验

### 方式零：前端一键导入（推荐）

管理员登录 → 右上角**账户菜单 → 导入演示数据**（`POST /api/db/import-demo`，幂等、不覆盖现有数据、无需重启）。配套**清除演示数据**按钮（`POST /api/db/clear-demo`）可一键清理全部「演示-」前缀数据。SQLite 与 MariaDB 部署均可使用（v1.9.7 起双后端化）。

### 方式一：CLI 种子脚本（写入当前 DB）

```bash
npm run dev   # 先启动服务以初始化 schema
npx tsx testdata/demo-exams/scripts/seed.ts
```

### 方式二：全量 ZIP 恢复

```bash
npm run dev
./testdata/demo-exams/scripts/import-all.sh restore   # 恢复后必须重启 dev 服务补齐迁移
```

### 方式三：重新生成备份包

```bash
./testdata/demo-exams/scripts/import-all.sh build
# 生成 backup/projectx-demo.zip（先 seed 到 .build/projectx.db 再 VACUUM INTO 导出；
# v1.9.9 起同时打包 data/answer-card/ 资源文件：填空题图片与网阅切块占位图，ZIP 恢复后图片完整可用）
```

### 校验

```bash
npx tsx testdata/demo-exams/scripts/verify.ts
```

verify.ts 自动处理管理员首次强制改密（读 `bootstrap-admin.txt` 一次性密码，登录响应要求改密时自动改为 `Admin@Demo2026` 并回写），校验点包括：年级/考试/跨考按周、并列排名、上次考试对比、学期对比、全局设置、文理分科标签与 track_type、语文卡填空题块、网阅双评/争议/断点续批/已批成绩。

## 5. 注意事项

- **幂等**：重复导入会先清理旧演示数据再重建（含 `review_sessions`），不会重复累积。
- **安全语义**：清理仅针对 `is_demo=1` 标记与「演示-」前缀，真实数据（`is_demo=0`）永不被误删；演示学号被真实数据占用时对应学生自动跳过，固定演示卡号被占用时导入会报错，需先处理冲突。
- **迁移版本**：当前数据依赖 v1~v34 迁移（v17 跳过）；ZIP 恢复后请重启服务自动补齐迁移。
- **资源文件**：填空题图片写入 `data/answer-card/assets/88000001/`，网阅占位图写入 `data/answer-card/recognition/crops/demo-review/`，清除演示数据后文件残留无害（DB 引用已级联删除）。
- **缺考说明**：演示-化学缺周杰（20260108）、演示-生物缺沈婷（20260116）为常规缺考测试点，与文理分科无关（文理分科仅作用于大考合集统计）。

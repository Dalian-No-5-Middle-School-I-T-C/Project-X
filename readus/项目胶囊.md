# Project-X 架构胶囊

## 项目
五中答题卡设计+阅卷+成绩分析系统。Win/Electron/React/Express/C++/Python LLM。

## 技术栈
前端 React19+TS+Vite7，后端 Express5+esbuild 打包，识别 C++(OpenCV+nlohmann/json)子进程调用，DB SQLite(better-sqlite3,WAL)，密码哈希 bcryptjs，桌面 Electron39，扫描仪 TWAIN C++桥(`native/ScannerBridge/`)，AI 分析中转为 Python FastAPI(`llmclient/`)。

## 关键目录
```
src/apps/answer-card/client/    # React: App.tsx(五模式:设计/阅卷/分析/我的成绩/账号), ScannerPanel, Analysis*, AnalysisAiPanel, NewCardModal, LoginPage, AccountManagement, TeacherManagement, ImportModal
src/apps/answer-card/server/    # Express: index.ts(路由), recognition.ts(C++子进程), storage.ts(JSON文件), scanner/(TWAIN), database/(scanner.db)
src/server/                     # 主DB(projectx.db): db/schema.sql, repositories/(Card/Exam/User/Analysis), services/AuthService.ts(登录+持久token)
src/shared/                     # types.ts, grading.ts, layout.ts, defaultCard.ts, pinyin.ts(科目→拼音), blankLabels.ts, appVariant.ts(多端变体)
native/AnswerCardRecognizer/    # C++识别引擎(answer-card-recognizer.exe)
native/ScannerBridge/           # C++ TWAIN扫描桥(scanner-bridge.exe)
resources/native/win-x64/       # 64 位打包用 native 资源
resources/native/win-ia32/      # 32 位打包用 native 资源
llmclient/                      # Python AI 中转服务：FastAPI、provider SDK、成绩工具白名单
data/answer-card/               # cards/*.json, layouts/*.json, scans/:cardId/, scanner.db, assets/:cardId/
```

## 核心类型
- `AnswerCard`: id/title/subject/subjectLabel/examDate/bodyBlocks(ObjectiveBlock|SubjectiveBlock)/sided("single"|"double")/studentInfo/layoutVersion
- `CardSummary`: id/title/subject/subjectLabel/examDate/updatedAt
- `LayoutDocument`: pages:PageLayout[](多页), elements:LayoutElement[]
- `ScanRecord`: session_id/card_id/student_id/image_path/page_num/side("front"|"back")/ocr_status
- `CombinedRecognitionResult`: studentId/questions[]/subjectiveQuestions[]
- `NewCardFormData`: subject/subjectLabel/title/examDate

## 数据流
```
设计器(React) → JSON(cards/layouts) → C++识别器(--image/--layout/--page) → grading.ts → SQLite
扫描仪 → TWAIN桥 → JPEG → scan_records → 自动OCR → recognition_results → 合并评分 → student_grading_results
```

## 关键函数
- `generateCardId(subject)` → 确定性8位纯数字(10000000~99999999)，defaultCard.ts
- `subjectToKey(chineseName)` → 中文科目→拼音key，pinyin.ts
- `buildLayout(card)` → LayoutDocument (layout.ts)
- `gradeCombinedRecognition(card,file,recognition)` → CombinedGradingRow (grading.ts)
- `gradeSessionStudentResults(card,pages[])` → CombinedStudentResult — 多页合并，Map去重优先非missing_key+高分
- `recognizeAnswerCard({imagePath,layoutPath,pageNumber,dpi})` → CombinedRecognitionResult (recognition.ts)
- `runScanSession(config,onProgress)` — 扫描+OCR全流程 (scanner-service.ts)

## 布局页码映射
单面: `layoutPage = pageNum`；双面: `layoutPage = (pageNum-1)*2 + (front?1:2)`

## 答题卡 ID & 管理 (2026-06-14)
- ID: `generateCardId(subject)` 确定性8位纯数字，科目→拼音key
- 导出: `GET /api/cards/:cardId/export` → `.projectx-card.json` (含answerKey+base64 assets+layout，即插即用)
- 导入: `POST /api/cards/import` → 重新生成ID，解码assets
- 删除: `DELETE /api/cards/:cardId` → 级联删除SQLite+JSON+layouts+assets
- 新建: NewCardModal弹窗(9科预设+其他手动+名称+日期选择器)
- 默认单面: sided='single'（defaultCard.ts + schema.sql）

## 认证 (2026-06-14)
- Token: 随机hex，`~/.projectx/tokens.json` 磁盘持久化，服务器重启不丢失
- 普通: 8小时过期；记住密码: 180天过期，重启服务器/软件均有效
- 前端: localStorage保存token，启动时`/api/auth/me`验证
- 登录页: 记住密码默认勾选，品牌「答题卡设计阅卷系统」

## 背面过滤(2026-06-13新增)
- 扫描仪直扫: scanner-service.ts 读 card.sided，single 时跳过 `side==="back"` 的 page
- 文件夹导入: App.tsx `addGradingFiles()` + server/index.ts grading端点，文件名匹配 `/B\.(jpg|jpeg|png|bmp|tiff|tif)$/i` 过滤
- 主DB answer_cards 表有 sided 列(自动migration)，CardRepository 已同步

## PDF式预览(2026-06-13)
ScannerPanel 扫描完成后按学生聚合展示，点击「查看」弹出全屏模态框，纵向滚动所有页面图片，底栏缩略图导航，PgUp/PgDn翻页。图片通过 `/api/scanner/scan-image/:recordId` 提供。

## 数据库
- projectx.db: answer_cards(...)/exams/student_scores/question_scores/users(username/name/student_number/subject/initial_password/...)/teacher_classes(teacher_id/class_id/subject/created_at)
- scanner.db(schema v2): scan_sessions/scan_records/recognition_results/student_grading_results(session_id+student_id联合主键)

## 约定
npm install 安装依赖；Windows 环境需 VS2022 v145。OpenCV x64 使用 `D:\opencv4-13\opencv\build`，OpenCV ia32 使用 `D:\opencv4-13\32\opencv_install_win32_vs18`。打包前按需运行 `npm run native:build:x64` 或 `npm run native:build:ia32`；`npm run electron:msi:all` 可生成三端 x64/ia32 共 6 个 MSI。AI 成绩分析需另行启动 `py -m uvicorn llmclient.server:app --host 127.0.0.1 --port 8766`。

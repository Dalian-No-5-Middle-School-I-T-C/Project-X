# Project-X 架构胶囊

## 项目
五中答题卡设计+阅卷+成绩分析系统。Win/Electron/React/Express/C++/Python LLM。

## 技术栈
前端 React19+TS+Vite7+react-router-dom v7（v2.0.0 Flat 2.0 设计系统落地：Tailwind v4 + `--px-*` 令牌 + `components/ui/v2` 组件库，旧 styles.css 已删），后端 Express5+esbuild 打包，识别 C++(OpenCV+nlohmann/json)子进程调用，DB 双后端：SQLite(better-sqlite3,WAL) / MySQL(mysql2,连接池,环境变量切换)，密码哈希 bcryptjs，桌面 Electron39，扫描仪 TWAIN C++桥(`native/ScannerBridge/`)，AI 分析中转为 Python FastAPI(`llmclient/`)。v1.9.4：网阅打分双模式(枚举/位值)+0.5小数+工作量均衡再分配+设置三层拆分；v2.1.0 皮肤扩展机制（`data-skin` + `SkinSwitcher` 注册表，账号级持久化）；v2.2.0 考试模式（quiz 晨测/formal 大考）+ 知识点难度/区分度；v2.3.0 第二套皮肤「纸锋 Paper Edge」。

## 核心类型
- `AnswerCard`: id/title/subject/subjectLabel/examDate/bodyBlocks(ObjectiveBlock|SubjectiveBlock)/sided("single"|"double")/studentInfo/layoutVersion
- `ObjectiveQuestionConfig`: questionNumber/mode/optionCount/score/answerKey/scoringRule，v1.3 起支持题级配置
- `ObjectiveScoringRule`: per_selected_count/by_correct_count/fixed_partial 三类部分得分规则
- `SubjectiveBlock`: blockKind("fill_blank"|"answer") + questions；填空可用 blanks.items 保存逐空标签/尺寸
- `CardSummary`: id/title/subject/subjectLabel/examDate/updatedAt
- `LayoutDocument`: pages:PageLayout[](多页), elements:LayoutElement[]
- `ScanRecord`: session_id/card_id/student_id/image_path/page_num/side("front"|"back")/ocr_status
- `CombinedRecognitionResult`: studentId/questions[]/subjectiveQuestions[]
- `NewCardFormData`: subject/subjectLabel/title/examDate

## 数据流
```
设计器(React) → SQLite结构化答题卡 → buildLayout派生layouts/*.json → C++识别器(--image/--layout/--page) → grading.ts → SQLite
扫描仪 → TWAIN桥 → JPEG → scan_records → 自动OCR → recognition_results → 合并评分 → student_grading_results
```

## 关键函数
- `generateCardId(subject)` → 确定性8位纯数字(10000000~99999999)，defaultCard.ts
- `subjectToKey(chineseName)` → 中文科目→拼音key，pinyin.ts
- `buildLayout(card)` → LayoutDocument (layout.ts)
- `applySubjectTemplate(card,options)` → 按语文/英语/数学/物理/化学/生物生成初始题块 (cardTemplates.ts)
- `objectiveQuestionDefinitions(block)` → 兼容旧块级字段并输出逐题定义 (grading.ts)
- `gradeCombinedRecognition(card,file,recognition)` → CombinedGradingRow (grading.ts)
- `gradeSessionStudentResults(card,pages[])` → CombinedStudentResult — 多页合并，Map去重优先非missing_key+高分
- `recognizeAnswerCard({imagePath,layoutPath,pageNumber,dpi})` → CombinedRecognitionResult (recognition.ts)
- `runScanSession(config,onProgress)` — 扫描+OCR全流程 (scanner-service.ts)

## 布局页码映射
单面: `layoutPage = pageNum`；双面: `layoutPage = (pageNum-1)*2 + (front?1:2)`

## 答题卡 ID & 管理 (2026-06-19更新)
- ID: `generateCardId(subject)` 确定性8位纯数字，科目→拼音key
- 导出: `GET /api/cards/:cardId/export` → `.projectx-card.json` (含answerKey+base64 assets+layout，即插即用)
- 导入: `POST /api/cards/import` → 弹出 ImportCardModal 确认卡片：可改科目/名称/日期，可选创建/关联考试（留空默认同答题卡名）
- 删除: `DELETE /api/cards/:cardId` → 若被考试引用先返回409；可传 `unlinkExams` 解绑考试，或 `deleteReferencedExams` 连同考试成绩一起删除
- 新建: NewCardModal弹窗(9科预设+其他手动+名称+日期选择器)
- 默认单面: sided='single'（defaultCard.ts + schema.sql）

## 学科模板 & 评分规则 (2026-06-17, v1.3.0)
- 科目模板: 语文、英语、数学、物理、化学、生物；英语可选听力，语文可选选择题卷首/按题号穿插

## 成绩修改模块 (v1.4.5~v1.4.6)
- `ScoreFixPage.tsx`: 双模式（个别改分 / 修改答案）。先选模式→搜索学生→逐题编辑
- 个别改分: 左侧答题卡图片（点击放大+缩放），右侧逐题分数下拉/输入
- 修改答案: 按钮组切换选项，保存后自动重算全部分数排名+赋分
- `StudentScoreDetail.tsx`: 点击成绩表行进入子页面，逐题得分+班级均分率+答题卡（点击放大，transform:scale 缩放）
- `ScoreDetailPage` Tab 栏右侧「分数有问题？」按钮（teacher/admin）
- API 路由: `src/server/routes/score-editing.ts`，含自动赋分重算

## 大考组 + 跨考内联 + 并列排名 + 导出增强 (v1.5.0 稳定版)
- 大考组: `exam_groups` + `exam_group_members` 表，通过 `source` 列隔离大考（NULL/manual）和跨考（cross-manual/week）

## 约定
npm install 安装依赖；Windows 环境需 VS2022 v145。OpenCV x64 使用 `D:\opencv4-13\opencv\build`，OpenCV ia32 使用 `D:\opencv4-13\32\opencv_install_win32_vs18`。打包前按需运行 `npm run native:build:x64` 或 `npm run native:build:ia32`；`npm run electron:dist` / `electron:msi` 生成扫描端 x64 包，`electron:dist:ia32` / `electron:msi:ia32` 生成 32 位包（v1.6.1 起仅扫描端打包，教师/学生端不再有 Electron 包）。AI 成绩分析需另行启动 `py -m uvicorn llmclient.server:app --host 127.0.0.1 --port 8766`。评分规则冒烟验证可运行 `npx tsx scripts/grading-rules-smoke.ts`。文档事实源见 AGENTS.md「样式事实源」（禁止新建 CSS / 硬编码 hex）。

# PR #248 成绩公布更新 — 发布说明与升级操作手册

> 版本：随主分支合并后定版 ｜ 日期：2026-08-25 ｜ 分支：`成绩公布更新`（HEAD f32325b + P1-2 工作区改动）
> 本文件是合入 main 前的**必读发布说明**：PR 引入两条对既有行为的破坏性变更，未适配将导致外部调用方/客户端行为异常。

## 一、功能概览

1. **成绩公布门控（v41）**：批改完成后成绩**默认不公布**（`score_published=0`），教师结考后手动公布（=1）、可撤回（=2）；学生端所有成绩接口只认 `score_published=1`。
2. **发布操作与审计（v42）**：单场/批量公布、撤回（含原因），`exam_publish_events` 全程审计；改分/改答案/仲裁/网阅/赋分重算等任一写分路径在**同一事务**内自动撤回公布（`markScoreMutated`）。
3. **发布完整性校验（P1-1 / P1-2）**：公布前必须「应考集合 ⊆ 已评分集合」；应考名单来自管理员显式名单或年级/班级名册快照（`exam_participants`，v47/v48 迁移）；**任何情况不再有「仅校验非空」退路**。

## 二、⚠️ 破坏性变更（合入前必须知晓）

### 变更 A：成绩默认不公布 → 学生端可见性变化

| 影响面 | 变化 |
|---|---|
| 学生端（Web / 小程序 `projectX-mini`） | 未公布考试**从成绩列表消失**；单场详情返回 **404**「该场考试的成绩尚未公布」；趋势/学期/学科对比**不含未公布场次**；天梯**403**；AI 分析**403** |
| 历史数据兼容 | v41 迁移已把存量 `status='closed'` 考试回填 `score_published=1`，升级后历史成绩对学生保持可见，**无需人工干预** |
| 小程序适配要求 | 前端需处理「待公布」状态：列表可提示"老师批改完成后公布"，详情 404 时展示"成绩尚未公布"而非"未找到成绩"（`projectX-mini` 各页 `wx.request` 失败分支需补该文案） |
| 教师/管理员 | **不受影响**：代查（`publishedOnly:false`）、考试详情、天梯均可见未公布成绩（`#246` 权限矩阵照常生效） |

### 变更 B：创建考试强制应考范围 → API 契约变更

| 影响面 | 变化 |
|---|---|
| `POST /api/exams` | 请求体**必须**含 `gradeId` 或 `classId`（至少其一），否则 400 `SCOPE_REQUIRED`「创建考试必须指定应考范围」 |
| 既有前端 | 已同步：考试管理页「新建考试」、答题卡设计器「同步创建考试」两个入口均新增年级/班级必选 |
| 外部集成 | 凡直接调用 `POST /api/exams` 的脚本/第三方集成需补传 `gradeId` 或 `classId`，否则创建失败 |
| 补充 | `PATCH /api/exams/:examId` 现支持补设 `gradeId/classId`（不允许清空）；与显式名单互斥（409） |

## 三、升级操作手册

### 3.1 数据库迁移（自动执行，无需人工）

- **SQLite**：启动时 `schema.sql` + `runMigrations` 自动执行 v47（`exam_participants`）、v48（`exam_participants.source`）。
- **MariaDB**：`getMysqlDb()` 首次连接时 `runMariadbMigrations` 自动执行 v47/v48（幂等，重复列自动忽略）。
- 迁移仅加表/加列，**不修改或删除既有数据**。

### 3.2 存量无范围考试的处置（合入后需管理员操作）

升级后若存在「未公布且无年级/班级范围」的历史考试（如早期 UI 创建、未补范围），**无法直接公布**，二选一处理：

1. **设置显式应考名单**（推荐，适合跨班/跨年级联考）：考试管理页 → 行内「应考名单」→ 按班级加载或搜索添加学生 → 保存。
2. **补设范围**：`PATCH /api/exams/:examId`，body `{ "classId": 5 }` 或 `{ "gradeId": 1 }`（需该考试无显式名单）。

> 已公布的存量考试不受影响（幂等早退）。

### 3.3 首次公布前的准备

- 考试必须有**应考范围**（年级/班级）或**显式名单**；
- 班级需已录入学生（空班级无法公布，提示「应考名单为空」）；
- 名册在首次阅卷/首次公布时**固化快照**——之后调班/转学不影响该场考试口径（如需按新名册，需清空显式名单后重新走班级快照，或人工调整名单）。

### 3.4 权限说明

- 公布/撤回/批量公布/名单管理均需 `grade:write`（教师默认拥有）+ 单场 `requireExamAccess` 数据范围（批量经 `getVisibleExamIds` 校验）；
- 批量公布单次上限 **200 场**（超限 400）。

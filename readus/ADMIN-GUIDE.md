# Project-X 管理员使用手册

> **适用版本**: v1.1.0 及以上  
> **适用角色**: 系统管理员（`admin`）  
> **关联文档**: [`ACCOUNT-ARCHITECTURE.md`](./ACCOUNT-ARCHITECTURE.md) · [`ACCOUNT-CONTROL.md`](./ACCOUNT-CONTROL.md)

本手册面向学校机房管理员、教务信息员，说明如何在 **答题卡设计系统（Electron 桌面版）** 中完成账号与班级的日常管理工作。

---

## 1. 开始之前

### 1.1 您需要什么权限？

只有 **管理员** 账号能看到顶部 **「账号」** 模式，并进行用户与班级管理。教师和学生的界面与此不同：

| 角色 | 登录后能看到什么 |
|------|------------------|
| **管理员** | 设计 · 阅卷 · 分析 · **账号** |
| **教师** | 设计 · 阅卷 · 分析 |
| **学生** | **我的成绩**（仅此一项） |

### 1.2 启动软件

1. 双击桌面图标 **「答题卡设计系统」**（或运行便携 EXE）。
2. 等待窗口加载完成，出现登录页面。

### 1.3 首次登录（非常重要）

系统第一次安装后自带默认管理员：

| 项目 | 内容 |
|------|------|
| 用户名 | `admin` |
| 密码 | `admin123` |

**请登录后立即修改密码**（见第 2 节）。默认密码切勿长期使用或在公开场合展示。

## 2. 登录与密码管理

### 2.1 登录

1. 在登录页输入 **用户名 / 学号 / 职工号** 和 **密码**。
2. 点击 **「登录」**。
3. 登录成功后进入主界面；右上角显示您的姓名与角色。

**登录说明：**

- 管理员、教师通常用 **用户名** 登录。
- 学生用 **学号**（纯数字）登录，初始密码默认为学号本身。

### 2.2 修改自己的密码

1. 点击右上角 **用户菜单**（显示您的姓名）。
2. 选择 **「修改密码」**。
3. 依次填写：**原密码**、**新密码**（至少 6 位）、**确认新密码**。
4. 点击 **「确认修改」**。
5. 修改成功后会自动退出，请用新密码重新登录。

### 2.3 退出登录

用户菜单 → **「退出登录」**。

---

## 3. 进入账号管理

1. 使用管理员账号登录。
2. 点击顶部模式栏中的 **「账号」**。
3. 页面分为两个子标签：
   - **用户管理** — 教师、学生、其他管理员账号
   - **班级管理** — 年级、班级、花名册

---

## 4. 用户管理

### 4.1 查看用户列表

**用户管理** 页顶部显示各角色人数统计。列表包含：

- 用户名、姓名、角色、学号、状态、最后登录时间

**筛选与搜索：**

| 操作 | 方法 |
|------|------|
| 按关键词搜索 | 在搜索框输入用户名、姓名或学号，按回车或点「刷新」 |
| 按角色筛选 | 下拉选择：全部 / 管理员 / 教师 / 学生 |
| 查看已禁用账号 | 勾选 **「含已禁用」** |

底部分页可翻页浏览；每页默认 20 人。

### 4.2 新建单个用户

1. 点击 **「新建用户」**。
2. 填写表单：

| 字段 | 说明 |
|------|------|
| 用户名 | 登录用，不可与已有用户重复 |
| 姓名 | 真实姓名，用于成绩表显示 |
| 角色 | 教师 / 学生 / 管理员（慎选） |
| 学号 | **学生必填**；教师/管理员可留空 |
| 初始密码 | 学生不填则默认为学号；教师/管理员必须填写 |
| 邮箱 | 可选 |

3. 点击 **「确认创建」**。

**示例 — 新建教师：**

- 用户名：`zhanglaoshi`
- 姓名：`张老师`
- 角色：教师
- 初始密码：`Wuzhong2026`（自行设定，告知教师）

**示例 — 新建学生：**

- 用户名：`2024001`（可与学号相同）
- 姓名：`李明`
- 角色：学生
- 学号：`2024001`
- 初始密码：留空（系统自动用学号 `2024001`）

### 4.3 批量导入学生（推荐）

适合开学初一次性导入全班学生。

1. 点击 **「批量导入学生」**。
2. 在文本框中按行粘贴，格式：

```
学号,姓名
学号,姓名,用户名（可选）
```

**示例：**

```
2024001,张三
2024002,李四
2024003,王五,2024003
```

3. 点击 **「开始导入」**。
4. 完成后提示成功人数与跳过人数（用户名或学号已存在时会跳过）。

导入规则：

- 用户名未写时，自动用学号作为用户名。
- 密码未指定时，自动用学号作为初始密码。
- 学生首次登录后应修改密码。

### 4.4 重置用户密码

当师生忘记密码时使用：

1. 在用户列表找到该用户。
2. 点击该行 **钥匙图标**（重置密码）。
3. 确认提示。

| 用户类型 | 重置结果 |
|----------|----------|
| 学生 | 默认重置为 **学号** |
| 教师/管理员 | 需在确认框中另行指定（若学号为空则须手动处理） |

重置后该用户所有已登录设备会自动失效，须用新密码重新登录。

### 4.5 禁用与重新启用账号

**禁用（学生转学、教师离职等）：**

1. 点击用户行 **禁用图标**（带叉的人形）。
2. 确认后账号变为「已禁用」，无法登录。

**重新启用：**

1. 勾选 **「含已禁用」** 找到该用户。
2. 点击 **启用图标**（带勾的人形）。

**注意：** 系统 **至少保留一名管理员**。无法禁用或降级最后一名管理员账号。

## 5. 班级管理

班级用于分析模块的 **按班筛选**，以及后续多班级统计。建议按「年级 → 班级 → 学生」顺序建立。

### 5.1 界面说明

班级管理页为三栏布局：

```
┌──────────┬──────────┬──────────────┐
│   年级   │   班级   │    花名册    │
│ 高一     │ 1 班     │ 张三 2024001 │
│ 高二     │ 2 班     │ 李四 2024002 │
└──────────┴──────────┴──────────────┘
```

### 5.2 新建年级

1. 切换到 **「班级管理」** 标签。
2. 在左侧 **年级** 栏输入名称（如 `2024级高一`）。
3. 点击 **「+」** 按钮。

### 5.3 新建班级

1. 在左侧选中一个年级。
2. 在中间 **班级** 栏输入名称（如 `1班`）。
3. 点击 **「+」** 按钮。班级旁会显示当前人数。

### 5.4 将学生加入班级（编花名册）

1. 在中间栏选中目标班级。
2. 在右侧 **花名册** 栏搜索框输入学号或姓名。
3. 按回车或点击 **添加图标** 搜索。
4. 在搜索结果中点击学生姓名，即可加入本班。

重复以上步骤，直到全班学生录入完毕。

### 5.5 将学生移出班级

在花名册中点击该学生右侧的 **移出图标**，确认即可。

### 5.6 删除班级或年级

| 操作 | 影响 |
|------|------|
| 删除班级 | 仅移除花名册关联，**不删除**学生账号 |
| 删除年级 | 级联删除其下所有班级及花名册，**不删除**学生账号 |

删除前系统会要求确认，请谨慎操作。

## 6. 推荐：新学期初始化流程

按以下顺序操作，可快速完成一个年级的部署：

```
① 管理员首次登录 → 立即修改默认密码
        ↓
② 班级管理：创建年级（如「2025级高一」）
        ↓
③ 班级管理：在该年级下创建班级（1班、2班……）
        ↓
④ 用户管理：批量导入全班学生（学号,姓名）
        ↓
⑤ 班级管理：逐班搜索学生并加入花名册
        ↓
⑥ 用户管理：为任课教师创建教师账号
        ↓
⑦ 通知师生：学生用「学号+学号」登录，教师用分配的用户名密码登录
        ↓
⑧ 教师端：设计答题卡 → 创建考试 → 阅卷 → 分析
        ↓
⑨ 学生端：登录后进入「我的成绩」查看分数
```

## 7. 与其他功能的关系

### 7.1 考试与成绩

- **考试** 在 **「分析」→「考试管理」** 中创建（教师/管理员均可，需相应权限）。
- 阅卷时关联考试 ID，成绩才会写入数据库。
- 学生只有在成绩落库后，才能在 **「我的成绩」** 中看到记录。

### 7.2 分析中的班级筛选

在 **「分析」→「成绩分析」** 中选择考试后，若已建立班级花名册，左侧会出现 **「班级筛选」** 下拉框，可按班查看统计。

### 7.3 阅卷时自动创建的学生

阅卷过程中，若学号对应的学生尚不存在，系统可能自动创建 **占位学生账号**（无初始密码）。此类账号需由管理员在 **用户管理** 中 **重置密码** 后，学生方可登录查分。

## 8. 常见问题

### Q1：忘记管理员密码怎么办？

需由技术人员在数据库中重置，或删除 `projectx.db` 后重启服务（**会丢失全部数据，仅适用于全新部署**）。生产环境请联系信息化部处理。

### Q2：学生登录提示「用户名或密码错误」

请检查：

1. 是否用 **学号** 登录（不是姓名）。
2. 初始密码是否为学号；若已重置，使用新密码。
3. 账号是否被 **禁用**（管理员勾选「含已禁用」查看）。

### Q3：批量导入时部分学生「跳过」

原因通常是 **用户名或学号已存在**。在列表中搜索该学号，确认是否重复录入。

### Q4：学生看不到成绩

请确认：

1. 阅卷时是否选择了 **考试**（否则成绩不入库）。
2. 该学号阅卷是否成功识别。
3. 学生是否用 **与阅卷学号一致** 的账号登录。

### Q5：能否有多个管理员？

可以。新建用户时角色选 **管理员** 即可。但系统始终要求 **至少保留一名** 有效管理员。

### Q6：教师能看到账号管理吗？

不能。教师无 `user:manage` 权限，界面上不会出现 **「账号」** 模式。

### Q7：登录后过一段时间又要重新登录

会话有效期为 **8 小时**；服务重启后所有会话也会失效。属于正常现象，重新登录即可。

## 9. 安全建议

1. **首次登录务必修改** 默认管理员密码。
2. 管理员密码应 **≥ 8 位**，含字母与数字，勿与其他系统共用。
3. 开学批量导入后，通知学生在 **首次登录后修改密码**。
4. 离职教师账号及时 **禁用**，勿长期闲置。
5. 机房电脑应限制无关人员物理访问；本系统数据存于本机，注意磁盘备份。
6. 不要将管理员密码写在贴于显示器的便签上。

# Project-X 管理员使用手册

> **适用版本**: v1.1.0 及以上  
> **适用角色**: 系统管理员（`admin`）  
> **关联文档**: [`ACCOUNT-ARCHITECTURE.md`](./ACCOUNT-ARCHITECTURE.md) · [`ACCOUNT-CONTROL.md`](./ACCOUNT-CONTROL.md)

本手册面向学校机房管理员、教务信息员，说明如何在 **答题卡设计系统（Electron 桌面版）** 中完成账号与班级的日常管理工作。

---

## 1. 开始之前

### 1.1 您需要什么权限？

只有 **管理员** 账号能看到顶部 **「账号」** 模式，并进行用户与班级管理。教师和学生的界面与此不同：

| 角色 | 登录后能看到什么 |
|------|------------------|
| **管理员** | 设计 · 阅卷 · 分析 · **账号** |
| **教师** | 设计 · 阅卷 · 分析 |
| **学生** | **我的成绩**（仅此一项） |

### 1.2 启动软件

1. 双击桌面图标 **「答题卡设计系统」**（或运行便携 EXE）。
2. 等待窗口加载完成，出现登录页面。

### 1.3 首次登录（非常重要）

系统第一次安装后自带默认管理员：

| 项目 | 内容 |
|------|------|
| 用户名 | `admin` |
| 密码 | `admin123` |

**请登录后立即修改密码**（见第 2 节）。默认密码切勿长期使用或在公开场合展示。

## 2. 登录与密码管理

### 2.1 登录

1. 在登录页输入 **用户名 / 学号 / 职工号** 和 **密码**。
2. 点击 **「登录」**。
3. 登录成功后进入主界面；右上角显示您的姓名与角色。

**登录说明：**

- 管理员、教师通常用 **用户名** 登录。
- 学生用 **学号**（纯数字）登录；v1.1 起学生账号格式为 `P+学号`（如 `P24101`），密码与账号相同。

### 2.2 修改自己的密码

1. 点击右上角 **用户菜单**（显示您的姓名）。
2. 选择 **「修改密码」**。
3. 依次填写：**原密码**、**新密码**（至少 6 位）、**确认新密码**。
4. 点击 **「确认修改」**。
5. 修改成功后会自动退出，请用新密码重新登录。

### 2.3 退出登录

用户菜单 → **「退出登录」**。

---

## 3. 进入账号管理

1. 使用管理员账号登录。
2. 点击顶部模式栏中的 **「账号」**。
3. 页面分为三个子标签：
   - **教师管理** — 教师账号、任教科目、关联班级
   - **学生管理** — 按年级→班级→花名册管理学生
   - **班级管理** — 年级、班级的创建与维护

---

## 4. 教师管理（v1.1 新增）

### 4.1 查看教师列表

**教师管理** 页按创建时间排序显示教师。列表包含：
- 教师姓名、任教科目

点击教师可查看详情。

### 4.2 批量导入教师

1. 点击 **「导入教师」**。
2. 上传 CSV/Excel 文件或粘贴文本，格式：

```
科目,姓名
物理,王建国
数学,李芳
```

3. 点击 **「确认导入」**。
4. 系统自动生成账号（`T+6位随机数`）和密码（6位随机数字）。

### 4.3 编辑教师

选中教师后可在右侧详情面板：
- 修改**姓名**
- 下拉选择**任教科目**（语文/数学/英语/物理/化学/生物/历史/地理/政治）
- 点击 **「保存」**

### 4.4 关联教师与班级

1. 选中教师 → 在「关联班级」区选择 **年级** → **班级**
2. 点击 **「关联」** 即可添加
3. 可关联多个班级（一位数理化老师可能教多个班）
4. 点击被关联班级旁的叉号可解除关联

### 4.5 导出教师账密

点击顶部常驻的 **「导出教师账密」** 按钮，下载 CSV/Excel 文件：

```csv
科目,姓名,账号,密码
物理,王建国,T482917,839205
```

> ⚠️ 导出文件含明文密码，请妥善保管，发放完成后删除文件。

## 5. 学生管理（v1.1 新增）

### 5.1 查看学生

**学生管理** 页为三栏布局：
- 左侧：年级列表
- 中间：选中年级下的班级列表（显示人数）
- 右侧：选中班级的花名册（学号、姓名、账号）

### 5.2 批量导入学生

1. 点击 **「导入学生」**。
2. 上传 CSV/Excel 文件或粘贴文本，格式：

```
年级,班级,学号,姓名
高一,高一1班,24101,张三
高一,高一1班,24102,李四
高一,高一2班,24103,王五
```

3. 点击 **「确认导入」**。

导入规则：
- 年级和班级不存在时自动创建
- 账号自动生成 `P+学号`（如 `P24101`）
- 密码 = 账号（`P24101`）
- 已存在的学号会被跳过

### 5.3 导出学生账密

点击顶部常驻的 **「导出学生账密」** 按钮，下载 CSV/Excel 文件：

```csv
年级,班级,学号,姓名,账号,密码
高一,高一1班,24101,张三,P24101,P24101
高一,高一1班,24102,李四,P24102,P24102
```

> ⚠️ 导出文件含明文密码，请妥善保管，发放完成后删除文件。

## 6. 班级管理

班级用于分析模块的 **按班筛选** 和教师关联。建议按「年级 → 班级 → 学生」顺序建立。

### 6.1 界面说明

班级管理页为三栏布局：

```
┌──────────┬──────────┬──────────────┐
│   年级   │   班级   │    花名册    │
│ 高一     │ 1 班     │ 张三 2024001 │
│ 高二     │ 2 班     │ 李四 2024002 │
└──────────┴──────────┴──────────────┘
```

### 6.2 新建年级

1. 切换到 **「班级管理」** 标签。
2. 在左侧 **年级** 栏输入名称（如 `2024级高一`）。
3. 点击 **「+」** 按钮。

### 6.3 新建班级

1. 在左侧选中一个年级。
2. 在中间 **班级** 栏输入名称（如 `1班`）。
3. 点击 **「+」** 按钮。班级旁会显示当前人数。

### 6.4 将学生加入班级（编花名册）

1. 在中间栏选中目标班级。
2. 在右侧 **花名册** 栏搜索框输入学号或姓名。
3. 按回车或点击 **添加图标** 搜索。
4. 在搜索结果中点击学生姓名，即可加入本班。

重复以上步骤，直到全班学生录入完毕。

> **提示**：如果学生尚未创建，可以先通过「学生管理 → 导入学生」批量创建并自动关联班级。

### 6.5 将学生移出班级

在花名册中点击该学生右侧的 **移出图标**，确认即可。

### 6.6 删除班级或年级

| 操作 | 影响 |
|------|------|
| 删除班级 | 仅移除花名册关联，**不删除**学生账号 |
| 删除年级 | 级联删除其下所有班级及花名册，**不删除**学生账号 |

删除前系统会要求确认，请谨慎操作。

## 7. 推荐：新学期初始化流程

按以下顺序操作，可快速完成一个年级的部署：

```
① 管理员首次登录 → 立即修改默认密码
        ↓
② 班级管理：创建年级（如「2025级高一」）
        ↓
③ 班级管理：在该年级下创建班级（1班、2班……）
        ↓
④ 学生管理：导入学生 CSV（含年级、班级、学号、姓名）
        ↓
⑤ 教师管理：导入教师 CSV（含科目、姓名）
        ↓
⑥ 教师管理：为教师关联任教班级
        ↓
⑦ 导出教师/学生账密 → 通知师生
        ↓
⑧ 教师端：设计答题卡 → 创建考试 → 阅卷 → 分析
        ↓
⑨ 学生端：登录后进入「我的成绩」查看分数
```

## 8. 与其他功能的关系

### 8.1 考试与成绩

- **考试** 在 **「分析」→「考试管理」** 中创建（教师/管理员均可，需相应权限）。
- 阅卷时关联考试 ID，成绩才会写入数据库。
- 学生只有在成绩落库后，才能在 **「我的成绩」** 中看到记录。

### 8.2 分析中的班级筛选

在 **「分析」→「成绩分析」** 中选择考试后，若已建立班级花名册，左侧会出现 **「班级筛选」** 下拉框，可按班查看统计。

### 8.3 阅卷时自动创建的学生

阅卷过程中，若学号对应的学生尚不存在，系统可能自动创建 **占位学生账号**（无初始密码）。此类账号需由管理员在 **用户管理** 中 **重置密码** 后，学生方可登录查分。

## 9. 常见问题

### Q1：忘记管理员密码怎么办？

需由技术人员在数据库中重置，或删除 `projectx.db` 后重启服务（**会丢失全部数据，仅适用于全新部署**）。生产环境请联系信息化部处理。

### Q2：学生登录提示「用户名或密码错误」

请检查：

1. 是否用 **学号** 登录（不是姓名）。
2. 初始密码是否为学号；若已重置，使用新密码。
3. 账号是否被 **禁用**（管理员勾选「含已禁用」查看）。

### Q3：批量导入时部分学生「跳过」

原因通常是 **用户名或学号已存在**。在列表中搜索该学号，确认是否重复录入。

### Q4：学生看不到成绩

请确认：

1. 阅卷时是否选择了 **考试**（否则成绩不入库）。
2. 该学号阅卷是否成功识别。
3. 学生是否用 **与阅卷学号一致** 的账号登录。

### Q5：能否有多个管理员？

可以。新建用户时角色选 **管理员** 即可。但系统始终要求 **至少保留一名** 有效管理员。

### Q6：教师能看到账号管理吗？

不能。教师无 `user:manage` 权限，界面上不会出现 **「账号」** 模式。

### Q7：登录后过一段时间又要重新登录

会话有效期为 **8 小时**；服务重启后所有会话也会失效。属于正常现象，重新登录即可。

## 10. 安全建议

1. **首次登录务必修改** 默认管理员密码。
2. 管理员密码应 **≥ 8 位**，含字母与数字，勿与其他系统共用。
3. 开学批量导入后，通知学生在 **首次登录后修改密码**。
4. 离职教师账号及时 **禁用**，勿长期闲置。
5. 机房电脑应限制无关人员物理访问；本系统数据存于本机，注意磁盘备份。
6. 不要将管理员密码写在贴于显示器的便签上。

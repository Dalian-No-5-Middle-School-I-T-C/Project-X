# Project-X 管理员使用手册

> **适用版本**: v1.5.0 及以上
> **适用角色**: 系统管理员（`admin`）  
> **关联文档**: [`ACCOUNT-ARCHITECTURE.md`](./ACCOUNT-ARCHITECTURE.md) · [`ACCOUNT-CONTROL.md`](./ACCOUNT-CONTROL.md)

本手册面向学校机房管理员、教务信息员，说明如何在 **答题卡设计系统（Electron 桌面版）** 中完成账号与班级的日常管理工作。

---

## 1. 开始之前

### 1.1 您需要什么权限？

只有 **管理员** 账号能看到顶部 **「账号」** 模式，并进行用户与班级管理。教师和学生的界面与此不同：

| 角色 | 登录后能看到什么 |
|------|------------------|
| **管理员** | 设计 · 阅卷 · 分析 · **账号** |
| **教师** | 设计 · 阅卷 · 分析 |
| **学生** | **我的成绩**（仅此一项） |

### 1.2 启动软件

1. 双击桌面图标 **「答题卡设计系统」**（或运行便携 EXE）。
2. 等待窗口加载完成，出现登录页面。

### 1.3 首次登录（非常重要）

系统第一次安装后会创建引导管理员：

| 项目 | 内容 |
|------|------|
| 用户名 | `admin` |
| 密码 | 数据库文件同目录 `bootstrap-admin.txt` 中的一次性密码 |

首次登录后系统会显示不可关闭的改密界面。改密成功后旧会话失效，`bootstrap-admin.txt` 自动删除。

## 2. 登录与密码管理

### 2.1 登录

1. 在登录页输入 **用户名 / 学号 / 职工号** 和 **密码**。
2. 点击 **「登录」**。
3. 登录成功后进入主界面；右上角显示您的姓名与角色。

**登录说明：**

- 管理员、教师通常用 **用户名** 登录。
- 学生可用 **学号**（纯数字，如 `24207`）或 **用户名**（`P`+学号）登录，密码默认为学号。

### 2.2 修改自己的密码

1. 点击右上角 **用户菜单**（显示您的姓名）。
2. 选择 **「修改密码」**。
3. 依次填写：**原密码**、**新密码**（至少 6 位）、**确认新密码**。
4. 点击 **「确认修改」**。
5. 修改成功后会自动退出，请用新密码重新登录。

### 2.3 退出登录

用户菜单 → **「退出登录」**。

---

## 3. 进入账号管理

1. 使用管理员账号登录。
2. 点击顶部模式栏中的 **「账号」**。
3. 页面分为两个子标签：
   - **教师管理** — 教师账号、任教科目、关联班级
   - **学生管理** — 按年级→班级→花名册管理学生（含年级/班级创建）

## 4. 教师管理（v1.1 新增）

### 4.1 查看教师列表

**教师管理** 页按创建时间排序显示教师。列表包含：
- 教师姓名、任教科目

点击教师可查看详情。

### 4.2 批量导入教师

1. 点击 **「导入教师」**。
2. 上传 CSV/Excel 文件或粘贴文本，格式：

```
科目,姓名
物理,王建国
数学,李芳
```

3. 点击 **「确认导入」**。
4. 系统自动生成账号（`T+6位随机数`）和密码（6位随机数字）。

### 4.3 编辑教师

选中教师后可在右侧详情面板：
- 修改**姓名**
- 下拉选择**任教科目**（语文/数学/英语/物理/化学/生物/历史/地理/政治）
- 点击 **「保存」**

### 4.4 关联教师与班级

1. 选中教师 → 在「关联班级」区选择 **年级** → **班级**
2. 点击 **「关联」** 即可添加（**即时生效，无需手动刷新**）
3. 可关联多个班级（一位数理化老师可能教多个班）
4. 点击被关联班级旁的叉号可解除关联（同样即时生效）

### 4.5 导出教师账密

点击顶部常驻的 **「导出教师账密」** 按钮，下载 Excel (.xlsx) 文件：

```csv
科目,姓名,账号,密码
物理,王建国,T482917,839205
```

> ⚠️ 导出文件含明文密码，请妥善保管，发放完成后删除文件。

## 5. 学生管理（v1.1 新增）

### 5.1 查看学生

**学生管理** 页为三栏布局：
- 左侧：年级列表
- 中间：选中年级下的班级列表（显示人数）
- 右侧：选中班级的花名册（学号、姓名、账号）

标题栏按钮统一为：**[刷新] [新建学生] [导入学生] [导出学生账密]**，与教师管理布局一致。

### 5.2 批量导入学生

1. 点击 **「导入学生」**。
2. 上传 CSV/Excel 文件或粘贴文本，格式：

```
年级,班级,学号,姓名
高一,高一1班,24101,张三
高一,高一1班,24102,李四
高一,高一2班,24103,王五
```

3. 点击 **「确认导入」**。

导入规则：
- 年级和班级不存在时自动创建
- 账号自动生成 `P+学号`（如 `P24101`）
- 密码 = 账号（`P24101`）
- 已存在的学号会被跳过

### 5.3 导出学生账密

点击顶部常驻的 **「导出学生账密」** 按钮，下载 CSV/Excel 文件：

```csv
年级,班级,学号,姓名,账号,密码
高一,高一1班,24101,张三,P24101,P24101
高一,高一1班,24102,李四,P24102,P24102
```

> ⚠️ 导出文件含明文密码，请妥善保管，发放完成后删除文件。

## 6. 年级与班级创建（在学生管理 Tab 内操作）

年级和班级的创建在 **「学生管理」** Tab 的三栏布局中完成。左侧创建年级，中间创建班级，右侧管理花名册。

### 6.1 界面说明

学生管理页为三栏布局：

```
┌──────────┬──────────┬──────────────┐
│   年级   │   班级   │    花名册    │
│ 高一     │ 1 班     │ 张三 2024001 │
│ 高二     │ 2 班     │ 李四 2024002 │
└──────────┴──────────┴──────────────┘
```

### 6.2 新建年级

1. 切换到 **「班级管理」** 标签。
2. 在左侧 **年级** 栏输入名称（如 `2024级高一`）。
3. 点击 **「+」** 按钮。

### 6.3 新建班级

1. 在左侧选中一个年级。
2. 在中间 **班级** 栏输入名称（如 `1班`）。
3. 点击 **「+」** 按钮。班级旁会显示当前人数。

### 6.4 将学生加入班级（编花名册）

**方式一：搜索并添加已有学生**

1. 在中间栏选中目标班级。
2. 在右侧 **花名册** 栏搜索框输入学号或姓名。
3. 按回车或点击搜索图标搜索。
4. 在搜索结果中点击学生姓名，即可加入本班。

**方式二：快捷新建学生并加入（推荐）**

1. 在右侧花名册栏下方「学号 + 姓名」输入框中分别填写。
2. 点击 **「+」** 按钮，立即创建学生并加入当前班级。
3. 交互模式与年级/班级创建完全一致（输入 → 加号 → 创建）。

**方式三：标题栏新建学生**

点击标题栏「新建学生」按钮，弹出对话框填写学号和姓名后创建（不自动关联班级）。

### 6.5 将学生移出班级

在花名册中点击该学生右侧的 **移出图标**，确认即可。

### 6.6 删除班级或年级

| 操作 | 影响 |
|------|------|
| 删除班级 | 仅移除花名册关联，**不删除**学生账号 |
| 删除年级 | 级联删除其下所有班级及花名册，**不删除**学生账号 |

删除前系统会要求确认，请谨慎操作。

## 7. 推荐：新学期初始化流程

按以下顺序操作，可快速完成一个年级的部署：

```
① 管理员首次登录 → 立即修改默认密码
        ↓
② 班级管理：创建年级（如「2025级高一」）
        ↓
③ 班级管理：在该年级下创建班级（1班、2班……）
        ↓
④ 学生管理：导入学生 CSV（含年级、班级、学号、姓名）
        ↓
⑤ 教师管理：导入教师 CSV（含科目、姓名）
        ↓
⑥ 教师管理：为教师关联任教班级
        ↓
⑦ 导出教师/学生账密 → 通知师生
        ↓
⑧ 教师端：设计答题卡（可同时创建/关联考试） → 阅卷 → 分析
        ↓
⑨ 学生端：登录后进入「我的成绩」查看分数
```

## 8. 与其他功能的关系

### 8.1 考试与成绩

- **考试** 在 **「分析」→「考试管理」** 中创建（教师/管理员均可，需相应权限）。
- 创建考试时选定答题卡后，考试名称和科目会**自动从答题卡回填**，无需重复输入。
- v1.3.0 起，答题卡若已被考试引用，删除时会先提示引用的考试名称。可选择仅解除考试与答题卡的关联后删除答题卡，也可选择连同这些考试及其成绩一起删除。
- 删除考试时也会提示是否同时删除关联答题卡；若只删除考试，答题卡会保留，可继续用于其他考试。
- **阅卷** 时选择考试后，答题卡会**自动关联**（根据考试绑定的答题卡），无需手动再选；也可以点击「换答题卡」手动覆盖。
- 阅卷时关联考试 ID，成绩才会写入数据库。
- 学生只有在成绩落库后，才能在 **「我的成绩」** 中看到记录。

### 8.2 答题卡学科模板

v1.3.0 起，新建答题卡会按所选科目自动填充常用题块。语文、英语、数学、物理、化学、生物已有默认模板；其他科目仍会使用通用答题卡结构。

- 英语模板可在新建弹窗中勾选是否包含听力题 1-20。
- 语文模板可选择把选择题统一放在卷首，或按原题号分散在主观题之间。
- 模板只是起点，教师仍可在设计器里继续修改题号、分值、答案、题块顺序和填空样式。

### 8.3 分析中的班级筛选

在 **「分析」→「成绩分析」** 中选择考试后，若已建立班级花名册，左侧会出现 **「班级筛选」** 下拉框，可按班查看统计。

### 8.4 AI 成绩分析

v1.2.0 起，「成绩分析」页面会在「分数统计分布」之后显示 AI 成绩分析卡片。教师可手动选择模型并生成报告，报告会根据当前考试和当前班级筛选范围读取统计数据。

AI 分析依赖单独启动的 Python `llmclient` 服务。如果按钮不可用，请先确认：

1. Python 服务是否已启动：`py -m uvicorn llmclient.server:app --host 127.0.0.1 --port 8766`。
2. `llmclient/.env` 或系统环境变量中是否配置了对应模型的 API Key。
3. `PROJECTX_DB_PATH` 是否指向当前 Electron 使用的 `%APPDATA%\answer-card-designer\data\projectx.db`。

详细配置见 [`AI成绩分析.md`](./AI成绩分析.md)。

### 8.5 阅卷时自动创建的学生

阅卷过程中，若学号对应的学生尚不存在，系统可能自动创建 **占位学生账号**（无初始密码）。此类账号需由管理员在 **用户管理** 中 **重置密码** 后，学生方可登录查分。

## 9. 常见问题

### Q1：忘记管理员密码怎么办？

需由技术人员在数据库中重置，或删除 `projectx.db` 后重启服务（**会丢失全部数据，仅适用于全新部署**）。生产环境请联系信息化部处理。

### Q2：学生登录提示「用户名或密码错误」

请检查：

1. 是否用 **学号** 登录（不是姓名）。
2. 初始密码是否为学号；若已重置，使用新密码。
3. 账号是否被 **禁用**（管理员勾选「含已禁用」查看）。

### Q3：批量导入时部分学生「跳过」

原因通常是 **用户名或学号已存在**。在列表中搜索该学号，确认是否重复录入。

### Q4：学生看不到成绩

请确认：

1. 阅卷时是否选择了 **考试**（否则成绩不入库）。
2. 该学号阅卷是否成功识别。
3. 学生是否用 **与阅卷学号一致** 的账号登录。

### Q5：能否有多个管理员？

可以。新建用户时角色选 **管理员** 即可。但系统始终要求 **至少保留一名** 有效管理员。

### Q6：教师能看到账号管理吗？

不能。教师无 `user:manage` 权限，界面上不会出现 **「账号」** 模式。

### Q7：登录后过一段时间又要重新登录

会话有效期为 **8 小时**；服务重启后所有会话也会失效。属于正常现象，重新登录即可。

---

### Q8：AI 成绩分析按钮不可用或生成失败？

AI 分析不是 Electron 自动启动的内置服务，需要先手动启动 `llmclient` Python 服务。若前端显示服务不可用，按以下顺序排查：

1. 访问 `http://127.0.0.1:8766/health`，确认 Python 服务在运行。
2. 检查 `GEMINI_API_KEY`、`DEEPSEEK_API_KEY` 或 `OPENAI_API_KEY` 是否配置。
3. 检查 `PROJECTX_DB_PATH` 是否指向 `%APPDATA%\answer-card-designer\data\projectx.db`。
4. 若 Electron 启动日志提示 `5174` 不可用，v1.2.0 会自动切换随机端口；这不影响 AI 分析，前端仍通过同源 Node 接口转发。

### Q9：删除答题卡时提示“已被考试引用”怎么办？

这是 v1.3.0 的删除保护。若只是想移除答题卡模板，选择“解绑考试并删除答题卡”；考试记录会保留，但不再绑定该答题卡。若该答题卡对应的考试和成绩都不再需要，可勾选连同引用考试一起删除。

## 10. 安全建议

1. **首次登录务必修改** 默认管理员密码。
2. 管理员密码应 **≥ 8 位**，含字母与数字，勿与其他系统共用。
3. 开学批量导入后，通知学生在 **首次登录后修改密码**。
4. 离职教师账号及时 **禁用**，勿长期闲置。
5. 机房电脑应限制无关人员物理访问；本系统数据存于本机，注意磁盘备份。
6. 不要将管理员密码写在贴于显示器的便签上。

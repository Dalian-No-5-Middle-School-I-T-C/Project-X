# Project-X 改造实施计划（2026-07-20）

> 依据 `readus/AUDIT-2026-07-20.md` 的审核结论，按用户选定方向制定：
> **网页模式 = 引入 react-router**（每功能 = 真实 URL 路由，可在新浏览器标签打开）；
> **前端统一风格** = 抽共享组件、回流内联样式；

## 0. 总原则

1. **不破坏现有功能**：每个阶段独立可上线、可回滚；阶段间用 git 分支隔离。
2. **状态外置优先于重写**：App.tsx 的 ~50 个 useState 不一次性拆散，先抽 `WorkspaceContext` 共享，再让各页面逐步私有化本地状态。
3. **设计令牌是唯一真相**：新增/修改 UI 一律走 `styles.css` 的 CSS 变量 + 共享组件，禁止新增内联 hex。
4. **路由是网页化的核心**：`mode` 状态 → URL；`mode-toggle` → `<NavLink>`；`switchMode` 的自动保存 → 路由导航守卫。

- 安装 `react-router-dom`（v6/v7）。

### 2.2 路由表（真实 URL，支持深链）
```
/login                                  → LoginPage（未登录入口）
/design[/:cardId]                       → DesignPage
/exam-manage                            → ExamManagePage（含 single/group 子态，state 或 ?tab=）
/grading                               → GradingPage
/analysis                              → AnalysisSelectPage

/account                               → AccountManagementPage
/sponsor /guide /permissions           → 对应页（如保留）
*                                      → <Navigate to={defaultMode} />
```
- 嵌套路由：分析类用 `<Outlet/>`，父路由 `AnalysisLayout` 提供子导航。

### 2.3 App.tsx 拆为 AppShell + 页面组件
- 新建 `src/apps/answer-card/client/AppShell.tsx`：保留 `.app-shell`（sidebar+topbar+statusbar+bottom-nav）作为 Layout，`<Outlet/>` 渲染当前页；`mode-toggle` 改为 `<NavLink to=...>`（active 态用 `.active`）；移动端 `bottom-nav` 同样用 `NavLink`。
- 抽出页面组件到 `client/pages/`：
  - `DesignPage.tsx`（原 design grid + sidebar/inspector 逻辑）
  - `ExamManagePage.tsx`、`GradingPage.tsx`、`AnalysisSelectPage.tsx` + `Analysis*/` 子页、`StudentScoresPage.tsx`、`AccountManagementPage.tsx`
- 每个页面内部保留原 JSX 结构与本地 UI 状态（如 `analysisTab`、`examManageMode`）。

### 2.4 状态外置：WorkspaceContext
- 新建 `client/context/WorkspaceContext.tsx`，提供跨页共享状态（来自原 App 的 ~50 个 useState 中真正跨页的）：
  - `cards / card / setCard`、`theme / setTheme`、`background`、`exams / examGroups / loadExams() / loadExamGroups()`、`flushPendingCardSave()`（原 `switchMode` 里的自动保存）。
- 页面通过 `useWorkspace()` 消费，避免一次性重写所有 prop drilling。
- 本地 UI 状态（如 `gradingFiles`、`analysisExamId`）各自留在页面内。

### 2.5 自动保存 → 导航守卫
- 原 `switchMode` 中的 `flushPendingCardSave` 改为：
  - `useBlocker`（react-router）在离开 `/design` 且有未保存更改时触发保存/确认；
  - `beforeunload` 兜底。
- 删除 `mode`/`previousModeRef`/`switchMode`，导航完全由 URL 驱动。

### 2.6 “每开一个功能新开一个界面”
- 在 `AppShell` 顶栏为每个 mode 的 `<NavLink>` 旁加“在新窗口打开”按钮（`window.open(location.origin + to, "_blank")`），实现“每功能新开一个浏览器界面”。
- 移动端 `bottom-nav` 的 `NavLink` 支持长按/菜单“新窗口打开”。
- 深链收益：刷新、`/analysis/exam/123` 直达、可分享链接。

### 2.7 Electron（可选，桌面体验）
- 当前 Electron 仅打包 Scanner（`ScannerApp`）。若要把教师端也做桌面多窗口：在 `electron/main.cjs` 用 `BrowserView` 或按需 `new BrowserWindow` 加载 `dist/web` 的各路由。属增强项，不在本期强制范围。

### 2.8 验收
- `npm run dev` 后：顶栏切换 = URL 变化；刷新停留在当前页；`/analysis/exam/123` 直达；点“新窗口打开”弹出独立标签且功能正常；移动端底部导航工作；`tsc --noEmit` 通过；无回归（原 9 功能均可达）。

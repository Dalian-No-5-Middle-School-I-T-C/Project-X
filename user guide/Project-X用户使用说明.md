# Project-X 智能试卷管理系统 · 使用说明

> **版本**：v2.0.0（含已合入未发版的 v2.1~v2.3 内部里程碑功能，如皮肤切换、纸锋皮肤、考试模式、知识点 P/D）  
> **适用**：Windows 10 / 11（扫描端）；任意带浏览器的设备（教师/学生 Web 端）  
> **项目**：大连市第五中学信息化部（I.T.C.）  

---

## 一、概述

Project-X 是一套**自主开发的智能试卷管理系统**，覆盖从答题卡设计、扫描/图片阅卷到成绩分析的全流程。系统由两个形态组成——

| 形态 | 访问方式 | 用途 |
|------|----------|------|
| **Web 端** | 浏览器访问学校部署地址（教师/学生通用） | 设计答题卡 · 考试管理 · 网上阅卷 · 成绩分析 · 账号管理 · 我的成绩 |
| **扫描端** | Windows 桌面程序（Electron，含 TWAIN 直扫） | 答题卡选择 · 扫描仪直扫 · 文件/目录导入阅卷（批量识别判分）· 结果预览 |

> **重要变化（v1.6.1 起）**：教师端、学生端**不再是独立的桌面安装包**，统一改为通过浏览器访问 Web 端；只有"扫描录入"保留为 Windows 桌面程序（扫描端）。  
> **重要变化（v1.9.0 起）**：Web 端取消独立「阅卷」入口，阅卷并入「考试管理」（网上阅卷）；批量图片导入判分位于**扫描端**工作台。  
> Web 端与扫描端共用**同一个后端与数据库**，在 Web 端（管理员）创建的账号、答题卡、考试，扫描端在本地或远程模式下均可直接使用。

## 二、部署与访问

### 2.1 教师 / 学生（Web 端）

无需安装任何软件。用电脑、手机或平板浏览器打开学校部署的 Web 地址，输入账号密码即可使用。推荐使用 Chrome / Edge / Safari 最新版。

### 2.2 扫描录入（扫描端，仅 Windows）

从 [GitHub Releases](https://github.com/Dalian-No-5-Middle-School-I-T-C/Project-X/releases) 下载扫描端安装包：

| 文件 | 适用 |
|------|------|
| `答题卡扫描端-x64.exe` / `答题卡扫描端-x64.msi` | 64 位 Windows |
| `答题卡扫描端-ia32.exe` / `答题卡扫描端-ia32.msi` | 32 位 Windows（兼容老机器） |

双击安装 → 开始菜单启动「答题卡扫描端」。便携版（`.exe`）可直接拷贝使用，适合临时/流动扫描。

### 2.3 运行环境要求

| 项目 | Web 端（教师/学生） | 扫描端（扫描录入） |
|------|------|------|
| 设备 | 电脑 / 手机 / 平板 + 浏览器 | Windows 10 / 11（64 或 32 位） |
| 内存 | 无特殊要求 | 4GB 以上 |
| 打印机 | A4 激光打印机（推荐） | 同左 |
| 扫描仪 | 不需要 | 柯达 i3000 系列（TWAIN 直扫） |

> 数据库支持**本地 SQLite**（单机/离线，默认）与**远程 MariaDB 10.11**（机房集中部署，多用户）双模式，由管理员在「账号设置 → 数据存储」中切换。

## 三、登录与账户

### 首次登录（管理员）

首次启动并初始化数据库后，系统自动创建管理员账号 `admin`，其**一次性随机密码**保存在数据库目录下的 `bootstrap-admin.txt` 文件中：

| 用户名 | 密码 |
|--------|------|
| `admin` | 见数据库旁的 `bootstrap-admin.txt`（随机一次性密码） |

**首次登录会强制要求修改密码。** 请打开数据库目录下的 `bootstrap-admin.txt` 获取初始密码，登录后按提示立即改密；改密成功后旧会话失效、该文件自动删除。

> 若从旧版本升级、数据库里仍残留 `admin123` 默认密码，首次登录会出现安全警告，请立即改密（系统会自动轮换旧密码）。新部署请直接使用 `bootstrap-admin.txt` 中的随机密码。

### 登录方式

- **管理员 / 教师**：用用户名（或工号）登录
- **学生**：用学号（如 `24101`）登录。**初始密码不是学号**——批量导入时由系统随机生成（8 位十六进制），由管理员通过「导出账密」Excel 发放；演示数据（`20260101` 等）除外，其密码为学号

> 阅卷时自动创建的占位学生账号无初始密码，需管理员在用户管理中「重置密码」后方可登录。首次登录后请立即修改初始密码。

### 记住密码

勾选登录页的「记住密码」，本机签发 180 天（约 6 个月）持久令牌，期间免登录。

### 会话时效

登录会话有效期 8 小时；服务重启后也会失效。长时间未操作被登出时，勾选「记住密码」可快速回到工作界面。

### 修改密码

右上角点击姓名 →「修改密码」→ 填写原密码和新密码（至少 6 位）→ 确认。

### 各角色能做什么

| 角色 | 可操作的功能 |
|------|------|
| 管理员 | 设计 · 阅卷 · 分析 · **账号管理** · **全局设置（含 AI 服务商、原卷策略）** |
| 教师 | 设计 · 阅卷（图片/网阅）· 分析 |
| 学生 | **我的成绩**（仅查看）· 成绩天梯 · 个人 AI 分析 |

管理员可为教师设置细分角色，自动限制数据可见范围：

| 细分角色 | 可见范围 |
|----------|----------|
| 学科老师（`subject_teacher`） | 仅本人所教科目 + 所教班级 |
| 班主任（`head_teacher`） | 本班级全部科目（限同年级） |
| 学年主任（`grade_leader`） | 全科目 + 全班级 + 全年级 |
| 未设置 | 保持全权限（向后兼容） |

## 四、功能使用

### 4.1 Home 仪表盘

登录后进入 Home 图形化首页：

- **模块卡片**：设计、阅卷、分析、账号等入口一目了然；
- **快捷入口**：「继续阅卷」（跳到上次未完成的网阅任务）、「最新考试」（直接看最近一场考试分析）；
- **Tab 栏**可开关，按习惯自定义首页布局。
- 右上角可切换**外观（明暗 / 皮肤）**，见 4.14 节。

### 4.2 新学期初始化（管理员必读）

```
① 登录 → 修改密码 → 账号 → 学生管理 → 创建年级（如"2025级高一"）
      ↓
② 在该年级下创建班级（1班、2班……）
      ↓
③ 导入学生（CSV/Excel，格式：年级,班级,学号,姓名；初始密码为系统随机生成，见第 4.11 节）
      ↓
④ 账号 → 教师管理 → 导入教师（格式：科目,姓名）
      ↓
⑤ 为教师关联任教班级
      ↓
⑥ 导出教师/学生账密 → 通知师生（账密含初始密码，注意保密）
      ↓
⑦ 教师端（Web）：设计答题卡 → 阅卷 → 分析
      ↓
⑧ 学生端（Web）：登录后查看成绩
```

### 4.3 设计答题卡

1. 切换到「**设计**」模式
2. 点击「**新建答题卡**」→ 选择科目、填写考试名称、**必填考试日期**（会自动创建/关联一场考试）
3. 系统自动填充该学科常用题块
4. 编辑题块和标准答案（添加/修改/删除题目），实时预览 → 点击「**保存**」
5. 点击「**导出 PDF**」→ 打印（缩放必须设为"实际大小"）

**题块编辑能力（按类型）**

- **客观题**：单选/多选/不定项；**选项排列**三种——横向、竖向（4 题一组）、**选项竖排**（A/B/C/D 在题号下方纵向堆叠，识别坐标自动跟随）。
- **解答题**：横线区 / 纯书写块 / **带分数填涂区**——「得分填涂格」开关常显，开启后自动出现得分格（数量与分值对应）。
- **填空题**：逐空自定义横线宽度/高度、右侧批注、**插入图片**（居中/靠左/靠右，可编辑尺寸与删除）、文字注释（题干说明）；得分格为**块级**——块内首题显示「计分题」开关与徽章，配合块级「满分」输入生效。
- **作文块**：仿高考样式作文格——默认**朱红格线**、每 100 字**字数刻度**（跨页续号）、粗边框 + 行间虚线 + 题号右对齐；可在面板调整「格线颜色」与目标字数（默认 600 字）。

**设计器布局**：三栏编辑区——右栏宽度可拖拽（300–560px）、左栏可折叠成细条（头部按钮或拖拽均可）、布局自动记忆；「适合页面」一键缩放预览（宽高双向约束，切换后不再漂移放大）。

> 语文模板可选择题统一放卷首或按题号穿插；英语模板可勾选是否包含听力 1-20 题。支持单/双面答题卡（双面卡扫描/阅卷时自动合并正反面、过滤背面）。  
> 答题卡可导出为 `.projectx-card.json`（含标准答案+配图+坐标布局），在其他机器上「导入」即用。  
> 导入演示数据（admin → 账户菜单）后，可在「答题卡设计」中直接查看演示用例：演示-语文卡含填空题块（自定义横线/插图/注释）与作文块（朱红格线/字数刻度），演示-数学卡客观题块为「选项竖排」布局。

### 4.4 图片导入阅卷（判分，扫描端）

> v1.9.0 起 Web 端取消独立「阅卷」入口，教师阅卷统一走「考试管理 → 网阅」的网上阅卷（见 4.5）；批量图片导入识别判分保留在**扫描端工作台**（直扫 / 导入图片二选一）。

1. 打开**扫描端** → 答题卡选择页选中答题卡 → 进入扫描工作台
2. 在右侧导入区**拖入/导入答题卡图片**（支持批量、支持目录）
3. 选择要落库的**考试**（答题卡自动关联）→ 点击「**开始识别判分**」
4. 系统自动完成：客观题填涂判分 + 主观题分数格识别 + 学号提取
5. 低置信度题目标"待复核"，可手工确认
6. 成绩自动入库；点击「**导出**」下载 Excel

> **重要**：阅卷时必须选择考试，成绩才会写入数据库，学生端才能查到。  
> 双面/多页卡会自动合并正反面成绩并去重汇总总分。  
> 识别成功后按大题块裁剪作答图片（大题切块），学生成绩详情与教师改分页优先展示切块，仍保留整页预览。

### 4.5 网上阅卷（多人协同打分）

v1.9.0 起支持正式的多人网上阅卷，适合期中/期末等大批量考试。入口：侧栏「**考试管理**」→ 选择考试 → 点「**网阅**」按钮。

**① 分配（年级组长 / 管理员）**
- 进入考试的「**网阅**」按钮 → 5 个管理 Tab：阅卷 / 阅卷分配 / 争议 / 溯源 / 网阅设置
- 在「分配」页为每个题块指定教师和份数，系统按 Fisher-Yates 随机均匀分配
- 可设置每题块的**复评模式**（单评 / 双评 / 三评）、分差阈值、取整方式（ceil/floor/round/half/none）、是否含 0.5 分、仲裁人、工作量均衡阈值

**② 阅卷（教师）**
- 从 Home「继续阅卷」进入，或在考试「网阅 → 阅卷」页自选题块
- 阅卷从**试卷池领卷**（v1.10.2）：汇总统计、条目列表、强制释放；阅完自动交回
- 新阅卷界面（PAD 优先）：**左图右分**，大按钮打分，滚轮缩放、90° 旋转
- 满分 < 20 走「枚举模式」点选大按钮；满分 ≥ 20 走「十位+个位+十分位」位值合成；含 0.5 时底部有专用 `0/0.5` 行
- **批注系统**：支持文字 + 手写批注（带 palm rejection），学生端可查看批注
- **断点续批**：退出自动保存进度和草稿分，重新进入弹窗恢复

**③ 多评与仲裁**
- 双评/三评独立打分，分差超阈值自动标记**争议**，交指定仲裁人（或年级组长手动判分）
- 阅卷**溯源**：每学生每轮评审人+分数可追溯
- 争议卷自动改派给已分配且未评过该生的教师

> 网阅与图片导入阅卷共用同一识别引擎；两种方式的结果都会写入同一考试数据库。

### 4.6 扫描仪直扫（仅扫描端）

1. 打开**扫描端**桌面程序，连接并开机扫描仪
2. **答题卡选择页**：搜索/按学科筛选答题卡，或切「大考」Tab 选考试组
3. 选卡后进入**扫描工作台**
4. 在 ScannerPanel 配置参数（DPI 建议 200-300）→ 点击「**开始扫描**」
5. 实时 SSE 进度 + 逐页缩略图预览，完成自动识别判分

两种阅卷方式可同用：**TWAIN 直扫**与**文件/目录导入阅卷**。

**本地 / 远程双模**：ScannerPanel 上方切换。
- 本地：识别结果存本机 SQLite；
- 远程：扫描完成自动三步上传（创建会话 → 逐页上传 → 标记完成）到远端服务器，需配置服务器地址 + 管理员生成的扫描端 API Key（登录页「服务器连接」折叠面板）。

> 识别成功后会按大题块**裁剪作答图片**（大题切块），跨页大题生成续页图片，学生成绩详情与教师改分页优先展示大题切块，仍保留整页预览。

### 4.7 查看成绩分析

切换到「**分析**」模式，考试选择页提供 **三选一**：

| 维度 | 说明 |
|------|------|
| **单科** | 按学年/年级/学科筛选单场考试 |
| **大考** | 大考组合集列表（如"2026 高考摸底"含语数英物化生） |
| **跨考** | 按周自动打包 / 手动选定考试 / 已存考试组，计算跨考总分排名 |

**大考组**：在「分析 → 大考组」创建合集，关联多场考试，统一查看各科参数卡片与跨科排名表（校排/班排/分数，赋分科目同行显示赋分）。

**6 个分析标签页**（单科/大考通用，v1.10.0 起）：

| 标签 | 看什么 |
|------|--------|
| 概况 | 人数、均分、最高最低、及格率、优秀率、标准差；**难度 P / 区分度 D** 指标卡、分数段条形图、箱型图、年级前五/后五、进步/退步前五 |
| 成绩 | 详细成绩表格（校排/班排/名次变化/偏差值/Z值/百分位），支持排序搜索；大考支持「合并/分科」视图切换与班级筛选 |
| 题目分析 | 逐题得分率表（表头可点击排序），点击行下钻查看每题每个学生的得分明细；知识点薄弱环节带难度 P / 区分度 D 徽章 |
| 班级对比 | 下拉选择基准班级，各班均分差值着色；大考下额外提供逐科班级均分对比 |
| 总体分析 | 直方图（叠加正态曲线）+ Q-Q 图 + 正态性检验（Shapiro-Wilk / KS / AD / 偏度 / 峰度），样本 < 30 时给出小样本提示 |
| AI 分析 | 多服务商 AI 生成结构化成绩报告 + **AI 知识点分析**（弱项诊断）；大考同样支持（按成员考试逐科汇总） |

> **考试模式**（v2.2.0）：创建考试时可选「晨测（quiz，教师全量可见）/ 大考（formal，精细权限）」，考试详情页管理员可随时切换，列表中显示晨测/大考徽章。

> **并列排名**：全系统排名统一为同分并列（如 1, 2, 2, 4, 5…），覆盖单科/大考/跨考/导出所有场景。  
> **原卷**：若考试已上传原卷（DOCX/PDF/图片），学生端可在成绩详情中查看原卷与教师批注。  
> **成绩修改**：教师/管理员可个别改分（逐题）或批量修改标准答案，修改后自动重算全部分数与排名；点学生行进入逐题得分明细（班级均分率 + 答题卡放大预览）。

### 4.8 导出成绩

在分析页点击「**导出**」→ 选择年级排名或班级排名 → 拖拽排列列顺序 → 下载 Excel。

- 单科导出可选「客观题小分」「主观题小分」胶囊列；
- 大考导出为 **ZIP**（总览表含跨科排名 + 各科详细小分 Excel）；
- 支持保存 4 个自定义导出模板，导出前可预览前 3 行。

### 4.9 AI 成绩分析 与 AI 知识点分析

**配置（管理员统一配置，v1.8.0 起）**：AI 服务商改为由管理员在「账号设置 → AI 服务商 / 全局设置」中集中维护（`is_system=1`），全校统一可用，**教师无需自行配置 API Key**。

1. 管理员添加服务商（GPT / DeepSeek / Gemini 等），填写 API Key 与 Base URL（Gemini 走原生 SDK，无需 Base URL）
2. 教师/学生进入「分析 → AI 分析」→ 选择已配置的服务商 → 输入模型名 →「生成分析」

**AI 知识点分析**：AI 自动分析每道题的知识点，以彩色标签呈现，教师可双击编辑；班级层面按得分率排序诊断薄弱知识点（如"勾股定理得分率 62%"），并带难度 P / 区分度 D 徽章。支持多模态直传（Gemini/GPT 看图）与 OCR 增强。

> 大考（考试组）详情页的「AI 分析」Tab 同样可用（v1.10.0 起），由模型按成员考试逐科汇总。

> 若 AI 分析不可用，请确认管理员已在「全局设置」配置并启用至少一个系统级 AI 服务商；AI 成绩分析依赖独立的 Python 中转服务（`llmclient`），需服务端另行启动。

### 4.10 配置赋分（新高考）

化学、生物、地理、政治等赋分科目，在考试管理中配置赋分公式：

- **等比例转换**：按比例映射赋分
- **线性公式**：如 `原始分 × 0.7 + 30`
- **自定义表达式**：自由输入公式

创建考试时和考后均可修改，实时重算并联动排名。

### 4.11 账号管理（仅管理员）

#### 批量导入学生

「账号」→「学生管理」→「导入学生」→ 上传或粘贴 CSV：

```
年级,班级,学号,姓名
高一,高一1班,24101,张三
高一,高一1班,24102,李四
```

导入规则：年级/班级自动创建，账号自动生成为 `P+学号`，**初始密码为系统随机生成的 8 位十六进制**（非学号），已在「导出账密」Excel 中列出，由管理员发放；已有学号自动跳过。

#### 批量导入教师

「账号」→「教师管理」→「导入教师」：

```
科目,姓名
物理,王建国
数学,李芳
```

系统自动生成账号（`T`+6 位随机数）和密码。

#### 导出账密

点击教师/学生管理页顶部的「导出账密」按钮，下载 Excel（学生账密含初始密码，教师账密含 6 位随机密码）。

> ⚠️ 导出文件含明文密码，发放完成后务必删除。

#### 重置密码

阅卷时自动创建的学生占位账号无初始密码，管理员在用户管理中**重置密码**后即可登录。

### 4.12 数据备份与恢复

右上角用户菜单 →「**导出数据**」→ 下载 ZIP 备份（SQLite: VACUUM；MariaDB: mysqldump）。

恢复：右上角菜单 →「**导入数据**」→ 上传 ZIP → 重启应用。

### 4.13 移动端使用（手机 / 平板）

教师/学生用手机或平板浏览器打开 Web 端地址即可完整使用全部功能。系统做了响应式适配：

- **表格卡片化**：手机下长表格自动转为卡片列表，便于阅读
- 输入控件已适配，iOS Safari 聚焦不再整体缩放

## 五、常见问题

### Q1：忘记管理员密码怎么办？

如 `bootstrap-admin.txt` 仍在数据库目录，用其中的一次性密码登录并改密；已删除则需管理员在数据库层面重置（联系信息化部，会重置管理员密码，不影响师生数据）。

### Q2：学生登录提示"用户名或密码错误"

先确认用的是**学号**（不是姓名）登录。初始密码不是学号，而是管理员导入时系统随机生成的 8 位十六进制（见「导出账密」Excel）；若已改过密码，用新密码。检查账号是否被禁用，或是否由占位账号（需管理员重置密码）。

### Q3：学生查不到成绩

请确认：
1. 阅卷时是否选择了**考试**（未选则成绩不入库）
2. 该学号是否被成功识别
3. 学生是否用与阅卷一致的学号登录

### Q4：批量导入时提示部分学生"跳过"

该学号已存在，在列表中搜索确认即可，无需重复导入。

### Q5：教师能看到账号管理吗？

不能。教师界面没有「账号」标签，账号管理仅管理员可用。

### Q6：登着登着又要重新登录

会话有效期 8 小时，服务重启后也会失效。勾选「记住密码」可 6 个月免登录。

### Q7：删除答题卡提示"已被考试引用"

选择"解绑考试并删除答题卡"即可只删模板、保留考试。如考试也不用了，可勾选连考试一起删除。

### Q8：Web 端看不到扫描入口

正常现象。Web 端用于教师/学生通过浏览器访问，不含硬件扫描功能。需要扫描仪直扫请使用 Windows **扫描端**桌面程序。

### Q9：AI 分析用不了

AI 功能需管理员先在「全局设置 → AI 服务商」中配置并启用系统级服务商（GPT / DeepSeek / Gemini 等）。教师/学生无需配置 API Key，直接选用即可。另需服务端启动 Python 中转服务（`llmclient`）。

### Q10：阅卷时自动创建的学生无法登录

此类占位账号无初始密码，管理员在用户管理中**重置密码**后即可登录。

### Q11：手机/平板上能用吗？

能。用手机或平板浏览器打开 Web 端地址即可，已做响应式适配（抽屉导航、表格卡片化）。扫描录入仍需 Windows 扫描端。

### Q12：什么是"大考组"和"跨考分析"？

- **大考组**：把多场考试（如语数英物化生）关联成一个合集，统一查看跨科排名。
- **跨考分析**：把不同考试的总分合并排名，支持按周自动打包、手动选定或读取已存考试组。

### Q13：成绩排名怎么有并列？

系统统一采用**同分并列**规则（如 1,2,2,4,5…），单科、大考、跨考、导出均一致。

### Q14：扫描端连接远端服务器失败

检查登录页「服务器连接」中服务器地址（如 `http://192.168.1.100:5174`）与 API Key 是否正确；API Key 由管理员在「账号设置 → API Key 管理」生成。

## 六、注意事项

1. **修改默认密码**：首次登录请立即修改 `admin` 的随机初始密码（来自 `bootstrap-admin.txt`）
2. **打印**：答题卡必须用 A4 纸，缩放设为"实际大小"，推荐激光打印机
3. **扫描**：答题卡保持平整无褶皱，DPI 建议 200-300；网络波动时扫描进度可能需手动刷新
4. **备份**：期中/期末等重要考试前后务必导出数据备份
5. **密码安全**：导出的账密文件用后即删，勿长期保留
6. **不要同时开多个端写同一数据**：Web 端与扫描端共用数据库，避免并发冲突
7. **数据清理**：周测扫描图片 30 天自动清理，月考 90 天，期中期末永久保留
8. **学生密码**：开学导入后提醒学生使用「导出账密」中的初始密码首次登录，并立即修改
9. **AI 配置集中化**：AI 服务商由管理员统一配置，教师不必各自申请 Key
10. **移动端**：阅卷/设计主力仍在电脑；手机/平板适合查看成绩与分析

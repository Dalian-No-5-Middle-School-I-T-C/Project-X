# Project-X 用户使用说明

> **适用版本**：v1.7.0 及以上  
> **适用对象**：管理员、教师、学生  
> **软件名称**：答题卡设计阅卷系统（Project-X）

Project-X 是大连市第五中学信息化部自主开发的智能试卷管理工具，支持答题卡设计、扫描识别、自动判分、成绩分析与账号管理。本文档面向日常使用人员，说明登录、各功能模块的操作方法与常见问题。

---

## 1. 两个端分别做什么

v1.6.1 起（v1.7.0 增强学生学期对比），系统拆分为 **Web 端** 与 **扫描端** 两个独立入口：

| 端 | 访问方式 | 默认首页 | 可见功能 |
|------|------|------|------|
| **Web 端** | 浏览器访问服务器地址 | 教师：设计；学生：我的成绩 | 设计、考试管理、阅卷（图片导入）、分析、账号、我的成绩 |
| **扫描端** | Electron 桌面应用 | 答题卡选择页 | 答题卡选择、TWAIN 扫描、文件/目录导入阅卷 |

**说明：**

- 教师和学生统一通过 **浏览器** 使用 Web 端，不再提供独立的教师端 / 学生端桌面程序。
- Web 端不含扫描仪代码，**扫描仪直扫** 仅在扫描端（Electron）中可用。
- 扫描端不含设计、分析、账号管理等页面，两端共用同一后端 API 与数据库。
- 前端会先按产品端限制功能，再按账号角色限制功能。例如：学生登录 Web 端只能看到「我的成绩」；管理员可在用户菜单中切换「教师 / 学生」视图进行预览。

## 2. 登录与密码

### 2.1 首次登录（管理员）

系统首次安装后自带默认管理员：

| 项目 | 内容 |
|------|------|
| 用户名 | `admin` |
| 密码 | 见数据库旁的 `bootstrap-admin.txt` 文件（随机一次性密码） |

**首次登录会强制要求修改密码。** 请打开数据库目录下的 `bootstrap-admin.txt` 获取初始密码，登录后按提示立即改密。

### 2.2 各角色登录方式

| 角色 | 登录名 | 默认密码 |
|------|------|------|
| 管理员 / 教师 | 用户名 | 由管理员分配 |
| 学生 | 用户名或学号 | 默认为学号 |

**登录说明：**

- 在浏览器或扫描端登录页输入 **用户名 / 学号 / 职工号** 和 **密码**。
- 勾选 **「记住密码（6 个月内免登录）」** 后，本设备重启后无需重复输入。
- 学生可用学号（如 `24207`）或用户名（如 `P24207`）登录，初始密码通常为学号。

### 2.3 修改自己的密码

1. 点击右上角 **用户菜单**（显示您的姓名）。
2. 选择 **「修改密码」**。
3. 填写原密码、新密码（至少 6 位）、确认新密码。
4. 修改成功后会自动退出，请用新密码重新登录。

### 2.4 退出登录

用户菜单 → **「退出登录」**。

### 2.5 管理员切换身份视图（Web 端）

管理员登录 Web 端后，可在用户菜单的 **「查看身份」** 区域切换教师 / 学生视图，用于预览不同角色看到的界面。切换即时生效，无需重新登录。

## 3. 界面与模式说明

登录 Web 端后，顶部模式栏按权限显示不同入口：

| 模式 | 适用角色 | 主要用途 |
|------|------|------|
| **设计** | 教师 / 管理员 | 新建、编辑答题卡，设置标准答案，导出 PDF |
| **考试管理** | 教师 / 管理员 | 创建考试、大考组，关联答题卡、管理阅卷批次 |
| **阅卷** | 教师 / 管理员 | 导入扫描图片，自动识别判分（Web 端不含扫描仪直扫） |
| **分析** | 教师 / 管理员 | 查看成绩概况、排名、题目分析、AI 分析 |
| **我的成绩** | 学生（及部分教师） | 查看个人各场考试得分、排名趋势与逐题明细 |
| **账号** | 管理员 | 管理教师、学生、班级与花名册 |

右上角 **用户菜单** 还提供：修改密码、账号设置、数据导入导出（管理员）、支持项目、退出登录。

**教师细分角色**（管理员在账号管理中设置）：

| 角色 | 数据可见范围 |
|------|------|
| 学科老师 | 本科目 + 自己所教班级 |
| 班主任 | 本班级全部科目（限同年级） |
| 学年主任 | 全科目 + 全班级 + 全年级 |

## 4. 设计答题卡

### 4.1 新建答题卡

1. 点击 **「新建答题卡」**。
2. 在弹窗中选择科目，填写考试名称和考试日期。
3. 系统会按科目自动生成常用题块模板（语文、英语、数学、物理、化学、生物等）。
4. 编辑标题、题块、标准答案后点击 **「保存」**。

### 4.2 常用操作

| 操作 | 说明 |
|------|------|
| 保存 | 保存当前答题卡 |
| 导出 PDF | 生成标准 A4 PDF，直接打印 |
| 导出 JSON | 侧边栏答题卡列表中导出 `.projectx-card.json` |
| 导入答题卡 | 从 JSON 文件导入，可同步创建或关联考试 |
| 删除答题卡 | 若已被考试引用，系统会提示是否解绑或连同考试一起删除 |

### 4.3 客观题与主观题

- **客观题**：支持单选、多选、不定项；可逐题设置题号、选项数、分值、标准答案与部分得分规则。
- **主观题**：支持带分数填涂区、填空题、横线格、空白大框等样式。
- **答题卡面**：可设为单面或双面；单面卡在阅卷时会自动过滤背面图片。

## 5. 考试管理与阅卷

### 5.1 创建考试

1. 切换到 **「考试管理」**。
2. 新建考试并关联答题卡（也可在新建答题卡时同步创建考试）。
3. 填写考试名称、科目、日期等信息。
4. 可创建 **大考组**，将多场考试（如语数英物化生）归入同一合集，便于统一分析与导出。

### 5.2 Web 端阅卷（图片导入）

1. 切换到 **「阅卷」**。
2. 选择考试（答题卡会自动关联，也可手动更换）。
3. 导入答题卡图片（支持多张或整个目录）。
4. 点击 **「开始识别并判分」**，等待识别完成。
5. 查看成绩表，可预览答题卡、导出 Excel。

**重要：** 阅卷时必须选择 **考试**，成绩才会写入数据库；否则学生无法在「我的成绩」中查看。

### 5.3 扫描端阅卷（Electron）

扫描端打开后分两步：

1. **答题卡选择页**：搜索或按学科筛选答题卡；也可切换到「大考」Tab 展开大考组，选择下辖考试对应的答题卡。
2. **扫描工作台**：选卡后进入，支持两种阅卷方式（可同时使用）：
   - **扫描仪直扫**：通过 TWAIN 驱动连接高速扫描仪（如柯达 i3000 系列），扫描完成后自动识别学号并判分。
   - **文件导入阅卷**：导入目录或单张图片，调用后端判分 API。

单面答题卡会自动跳过背面扫描结果。

### 5.4 扫描端远程模式

扫描端支持 **本地** 与 **远程** 双模，在扫描工作台上方切换：

| 模式 | 数据存储 | 扫描图片 | 答题卡来源 |
|------|---------|---------|-----------|
| **本地**（默认） | 本机 SQLite | 本机 | 本机数据库 |
| **远程** | 远端服务器 | 上传到远端 | 远端 API |

**远程模式配置**：在登录页展开 **「服务器连接（可选）」**，填入：

- **服务器地址**：如 `http://192.168.1.100:5174`
- **API Key**：管理员在账号设置 → API Key 中生成的扫描专用 Key

扫描完成后自动三步上传：创建会话 → 逐页上传图片 → 标记完成。

## 6. 成绩分析

1. 切换到 **「分析」**。
2. 在考试选择页按 **[单科 | 大考 | 跨考]** 切换分析维度：
   - **单科**：按学年 / 年级 / 学科筛选并选择考试。
   - **大考**：选择大考组，查看跨科汇总分析。
   - **跨考**：按周打包、手动选择或已存组，计算跨考试总分排名。
3. 在 **概况 / 成绩 / 考试分析 / AI 分析** 等子页查看数据。
4. 可按班级筛选，导出 Excel 成绩表或大考 ZIP 包。
5. 教师 / 管理员可点击 **「分数有问题？」** 进入成绩修改页面（个别改分或批量修改答案）。

### 6.1 AI 成绩分析

> **重要**：所有 AI 功能（成绩 AI 分析、原卷知识点分析、学生 AI 建议）都经由后端调用的 **Python 中转服务 `llmclient`** 真正访问大模型。因此**无论用哪种服务商，都需要 `llmclient` 在运行**——旧版说明中"自定义服务商无需启动 Python"已不准确，当前版本所有 AI 调用都经 `llmclient` 中转。

**llmclient 自动启动（推荐，v1.9.4+）**

Node 后端启动时会**自动拉起** `llmclient`（默认 `http://127.0.0.1:8766`），一般无需手动启动：

- 关闭自动启动：`LLMCLIENT_AUTOSTART=false`
- 指定 Python 解释器：`LLMCLIENT_PYTHON`（默认 Windows 用 `py`、Linux/macOS 用 `python3`；若依赖装在某个虚拟环境，指向该环境的 python）
- 监听地址 / 端口：跟随 `LLMCLIENT_URL`（默认 `http://127.0.0.1:8766`）

若自动启动失败（如找不到 Python 或依赖未装），后端日志会打印 `[llmclient] …` 提示，AI 功能暂不可用，但**不会拖垮主服务**；此时可手动启动（见下）或修正上面的环境变量后重启。

**手动启动（可选）**

```text
py -m uvicorn llmclient.server:app --host 127.0.0.1 --port 8766
```

并在 `llmclient/.env` 中配置对应模型的 API Key（`GEMINI_API_KEY` / `DEEPSEEK_API_KEY` / `OPENAI_API_KEY` 等）。

**服务商配置（两种来源，最终都经 llmclient 转发）**

- **内置服务商**：在 `llmclient/.env` 配置模型 API Key，由 llmclient 默认使用。
- **自定义 / 系统服务商**：在 **全局设置 → AI 系统配置**（管理员）或 **账号设置 → AI 服务商** 中添加（类型 GPT / DeepSeek / Gemini + API Key + Base URL）。这些凭证会作为 `providerOverride` 通过 llmclient 转发给对应模型，**并非直连**——因此仍依赖 llmclient 运行。

若 AI 按钮不可用，请检查：`llmclient` 是否运行（访问 `http://127.0.0.1:8766/health` 应返回 `{"ok":true}`）、API Key 是否配置、模型凭证是否正确。

## 7. 学生查看成绩

1. 使用学生账号在浏览器中登录 **Web 端**。
2. 进入 **「我的成绩」**。
3. 在子 Tab 中切换：
   - **成绩列表**：选择考试，查看总分、排名与逐题得分明细。
   - **趋势分析**：按学科查看历次考试分数曲线，可叠加班级/年级均分。
   - **学科对比**：横向比较各学科平均分与班级均分差距，标注薄弱学科。
   - **学期对比**（v1.7.0+）：查看本学期 vs 上学期的均分变化、进步/退步学科。
   - **AI 分析**：基于个人成绩生成学习建议（需配置 AI 服务商）。
   - **成绩天梯**：查看年级前十名榜单（单科 / 大考 / 跨考累计三种维度；管理员可开关）。

若看不到成绩，请确认：阅卷时是否选择了考试、学号是否识别成功、是否用与阅卷学号一致的账号登录。

## 8. 账号管理（管理员）

管理员在 **「账号」** 模式中管理师生账号：

### 8.1 教师管理

- 批量导入教师（CSV/Excel：`科目,姓名`）。
- 编辑任教科目，设置细分角色（学科老师 / 班主任 / 学年主任）。
- 关联任教班级。
- 导出教师账密 Excel。

### 8.2 学生管理

- 三栏布局：年级 → 班级 → 花名册。
- 批量导入学生（CSV/Excel：`年级,班级,学号,姓名`）。
- 快捷新建学生并加入班级。
- 导出学生账密 Excel。

### 8.3 新学期推荐流程

```
① 管理员首次登录 → 立即修改默认密码
        ↓
② 学生管理：创建年级与班级
        ↓
③ 导入学生 CSV
        ↓
④ 导入教师 CSV → 关联任教班级
        ↓
⑤ 导出账密 → 通知师生
        ↓
⑥ 教师 Web 端：设计答题卡 → 阅卷 → 分析
        ↓
⑦ 学生 Web 端：登录查看成绩
```

## 9. 数据与备份

### 9.1 Web 端（服务器部署）

数据默认存放在项目根目录：

```text
data/projectx.db
data/answer-card/
```

管理员可通过环境变量自定义路径（详见运维文档）。

### 9.2 扫描端（Electron 本地模式）

数据存放在：

```text
%APPDATA%\answer-card-designer\data\projectx.db
%APPDATA%\answer-card-designer\data\answer-card\
```

### 9.3 备份与恢复

管理员可在用户菜单中 **导出数据**（ZIP 备份）或 **导入数据**（恢复备份，需重启应用）。

**注意：** 扫描端与 Web 端若共用同一数据库，建议不要同时写入，避免 SQLite 冲突。远程模式下扫描端数据存储在服务器。

## 10. 常见问题

### Q1：学生登录提示「用户名或密码错误」

1. 确认是否用 **学号** 或 **用户名** 登录（不是姓名）。
2. 初始密码是否为学号；若已重置，使用新密码。
3. 确认访问的是正确的 Web 端地址。
4. 请管理员在账号管理中确认该学生是否存在、是否被禁用。

### Q2：学生看不到成绩

1. 阅卷时是否选择了 **考试**。
2. 该学号阅卷是否成功识别。
3. 学生是否用与阅卷学号一致的账号登录。

### Q3：Web 端看不到扫描入口

这是正常的。Web 端用于教师 / 学生通过浏览器访问，不含硬件扫描功能。扫描仪录入请使用 **扫描端**（Electron 桌面应用）。

### Q4：删除答题卡时提示「已被考试引用」

可选择 **解绑考试并删除答题卡**（保留考试记录），或 **连同引用考试及其成绩一起删除**。

### Q5：登录后过一段时间又要重新登录

未勾选「记住密码」时会话有效期为 8 小时；属于正常现象，重新登录即可。

### Q6：忘记管理员密码怎么办

需由技术人员在数据库中重置，或删除 `projectx.db` 后重启（**会丢失全部数据，仅适用于全新部署**）。生产环境请联系信息化部处理。

### Q7：从旧版 Electron 教师端 / 学生端迁移

v1.6.1 已废弃独立的教师端 / 学生端 Electron 打包：

1. **学生**：引导其通过浏览器访问 Web 端部署地址。
2. **教师**：引导其通过浏览器访问 Web 端；如需扫描，使用扫描端（Electron）。
3. 数据目录不变，迁移到 Web 端后可直接使用原数据。

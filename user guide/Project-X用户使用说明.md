# Project-X 用户使用说明

> **适用版本**：v1.4.5 及以上  
> **适用对象**：管理员、教师、学生  
> **软件名称**：答题卡设计阅卷系统（Project-X）

Project-X 是大连市第五中学信息化部自主开发的智能试卷管理工具，支持答题卡设计、扫描识别、自动判分、成绩分析与账号管理。本文档面向日常使用人员，说明登录、各功能模块的操作方法与常见问题。

---

## 1. 三个端分别做什么

系统按角色提供三个独立桌面端，默认共用同一套本机数据：

| 端 | 默认首页 | 可见功能 |
|------|------|------|
| **学生端** | 我的成绩 | 仅查看个人成绩与逐题明细 |
| **教师普通端** | 设计 | 设计、考试管理、阅卷、分析、账号 |
| **教师扫描端** | 阅卷 | 设计、考试管理、阅卷、分析、账号、扫描仪录入 |

前端会先按产品端限制功能，再按账号角色限制功能。例如：管理员登录学生端也只能看到「我的成绩」；学生登录教师端不会获得教师功能。

## 2. 登录与密码

### 2.1 首次登录（管理员）

系统首次安装后自带默认管理员：

| 项目 | 内容 |
|------|------|
| 用户名 | `admin` |
| 密码 | `admin123` |

**请登录后立即修改密码。** 默认密码切勿长期使用。

### 2.2 各角色登录方式

| 角色 | 登录名 | 默认密码 |
|------|------|------|
| 管理员 / 教师 | 用户名 | 由管理员分配 |
| 学生 | 用户名或学号 | 默认为学号 |

**登录说明：**

- 登录页可输入 **用户名 / 学号 / 职工号** 和 **密码**。
- 勾选 **「记住密码（6 个月内免登录）」** 后，本设备重启软件无需重复输入。
- 学生可用学号（如 `24207`）或用户名（如 `P24207`）登录，初始密码通常为学号。

### 2.3 修改自己的密码

1. 点击右上角 **用户菜单**（显示您的姓名）。
2. 选择 **「修改密码」**。
3. 填写原密码、新密码（至少 6 位）、确认新密码。
4. 修改成功后会自动退出，请用新密码重新登录。

### 2.4 退出登录

用户菜单 → **「退出登录」**。

## 3. 界面与模式说明

登录后，顶部模式栏按权限显示不同入口：

| 模式 | 适用角色 | 主要用途 |
|------|------|------|
| **设计** | 教师 / 管理员 | 新建、编辑答题卡，设置标准答案，导出 PDF |
| **考试管理** | 教师 / 管理员 | 创建考试、关联答题卡、管理阅卷批次 |
| **阅卷** | 教师 / 管理员 | 导入扫描图片或扫描仪直扫，自动识别判分 |
| **分析** | 教师 / 管理员 | 查看成绩概况、排名、题目分析、AI 分析 |
| **我的成绩** | 学生（及部分教师） | 查看个人各场考试得分与逐题明细 |
| **账号** | 管理员 | 管理教师、学生、班级与花名册 |

右上角 **用户菜单** 还提供：修改密码、账号设置、数据导入导出（管理员）、支持项目、退出登录。

## 4. 设计答题卡

### 4.1 新建答题卡

1. 点击 **「新建答题卡」**。
2. 在弹窗中选择科目，填写考试名称和考试日期。
3. 系统会按科目自动生成常用题块模板（语文、英语、数学、物理、化学、生物等）。
4. 编辑标题、题块、标准答案后点击 **「保存」**。

### 4.2 常用操作

| 操作 | 说明 |
|------|------|
| 保存 | 保存当前答题卡到本机 |
| 导出 PDF | 生成标准 A4 PDF，直接打印 |
| 导出 JSON | 侧边栏答题卡列表中导出 `.projectx-card.json` |
| 导入答题卡 | 从 JSON 文件导入，可同步创建或关联考试 |
| 删除答题卡 | 若已被考试引用，系统会提示是否解绑或连同考试一起删除 |

### 4.3 客观题与主观题

- **客观题**：支持单选、多选、不定项；可逐题设置题号、选项数、分值、标准答案与部分得分规则。
- **主观题**：支持带分数填涂区、填空题、横线格、空白大框等样式。
- **答题卡面**：可设为单面或双面；单面卡在阅卷时会自动过滤背面图片。

## 5. 考试管理与阅卷

### 5.1 创建考试

1. 切换到 **「考试管理」**。
2. 新建考试并关联答题卡（也可在新建答题卡时同步创建考试）。
3. 填写考试名称、科目、日期等信息。

### 5.2 阅卷判分

1. 切换到 **「阅卷」**。
2. 选择考试（答题卡会自动关联，也可手动更换）。
3. 导入答题卡图片，或使用扫描仪直扫（仅教师扫描端）。
4. 点击 **「开始识别并判分」**，等待识别完成。
5. 查看成绩表，可预览答题卡、导出 Excel。

**重要：** 阅卷时必须选择 **考试**，成绩才会写入数据库；否则学生无法在「我的成绩」中查看。

### 5.3 扫描仪直扫（教师扫描端）

- 支持通过 TWAIN 驱动连接高速扫描仪（如柯达 i3000 系列）。
- 扫描完成后可预览多页答题卡，系统自动识别学号并判分。
- 单面答题卡会自动跳过背面扫描结果。

## 6. 成绩分析

1. 切换到 **「分析」**。
2. 按学年 / 年级 / 学科筛选并选择考试。
3. 在 **概况 / 成绩 / 考试分析 / AI 分析** 等子页查看数据。
4. 可按班级筛选，导出 Excel 成绩表。
5. 教师 / 管理员可点击 **「分数有问题？」** 进入成绩修改页面。

### 6.1 AI 成绩分析

AI 分析需先在 **账号设置 → AI 服务商** 中配置 API，并启动 Python 中转服务：

```text
py -m uvicorn llmclient.server:app --host 127.0.0.1 --port 8766
```

若按钮不可用，请检查 Python 服务是否运行、API Key 是否配置。

## 7. 学生查看成绩

1. 使用学生账号登录 **学生端**（或仅有成绩权限的账号）。
2. 进入 **「我的成绩」**。
3. 选择考试，查看总分、排名与逐题得分明细。

若看不到成绩，请确认：阅卷时是否选择了考试、学号是否识别成功、是否用与阅卷学号一致的账号登录。

---

## 8. 账号管理（管理员）

管理员在 **「账号」** 模式中管理师生账号：

### 8.1 教师管理

- 批量导入教师（CSV/Excel：`科目,姓名`）。
- 编辑任教科目，关联任教班级。
- 导出教师账密 Excel。

### 8.2 学生管理

- 三栏布局：年级 → 班级 → 花名册。
- 批量导入学生（CSV/Excel：`年级,班级,学号,姓名`）。
- 快捷新建学生并加入班级。
- 导出学生账密 Excel。

### 8.3 新学期推荐流程

```
① 管理员首次登录 → 立即修改默认密码
        ↓
② 学生管理：创建年级与班级
        ↓
③ 导入学生 CSV
        ↓
④ 导入教师 CSV → 关联任教班级
        ↓
⑤ 导出账密 → 通知师生
        ↓
⑥ 教师端：设计答题卡 → 阅卷 → 分析
        ↓
⑦ 学生端：登录查看成绩
```

## 10. 常见问题

### Q1：学生登录提示「用户名或密码错误」

1. 确认是否用 **学号** 或 **用户名** 登录（不是姓名）。
2. 初始密码是否为学号；若已重置，使用新密码。
3. 确认三个端是否访问同一数据目录。
4. 请管理员在账号管理中确认该学生是否存在、是否被禁用。

### Q2：学生看不到成绩

1. 阅卷时是否选择了 **考试**。
2. 该学号阅卷是否成功识别。
3. 学生是否用与阅卷学号一致的账号登录。

### Q3：删除答题卡时提示「已被考试引用」

可选择 **解绑考试并删除答题卡**（保留考试记录），或 **连同引用考试及其成绩一起删除**。

### Q4：登录后过一段时间又要重新登录

未勾选「记住密码」时会话有效期为 8 小时；属于正常现象，重新登录即可。

### Q5：忘记管理员密码怎么办

需由技术人员在数据库中重置，或删除 `projectx.db` 后重启（**会丢失全部数据，仅适用于全新部署**）。生产环境请联系信息化部处理。

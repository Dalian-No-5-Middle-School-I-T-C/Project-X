## 已确认并修复的问题

| 问题 | 修复与验证 |
|---|---|
| MariaDB 保存设置、成绩和阅卷状态时报日期格式错误 | 为数据库日期字段统一提供兼容格式，覆盖设置、分析阈值、改分、阅卷、扫描持久化和清理截止时间。保持 SQLite ISO 格式；MariaDB 与 mysql2 的本地时区读写约定一致，验证北京时间及 UTC 往返。 |
| 大考总体分析派生表缺少别名 | 补齐 `full_participants` 别名，真实 MariaDB 上验证大考六个分析接口。截图中的保留字 UPSERT 和另一处 GROUP BY 已在当前代码基线修复，本轮继续以真实数据库验证。 |
| 单科分析页面整个崩溃 | 实际浏览器复现 `"bar" is not a registered controller`；统一图表适配器补注册柱状、折线、环形、雷达、散点控制器及径向坐标。七个分析页签实际打开验收。 |
| Python AI 读取 MariaDB 失败 | 修复聚合派生表别名、`CAST AS REAL` 方言不兼容；对日期和 Decimal 进行 JSON 转换。 |
| 知识点工具无法调用 | 修复注册器 camelCase 参数与函数签名不一致，以及调用不存在的连接函数；七个成绩工具逐个执行并检查 JSON 可序列化。 |
| AI 非百分制分析结论错误 | 及格、优秀线改为读取全局比例并乘实际满分；分数段采用配置粒度和连续边界，保留小数成绩及超过 100 分的成绩；百分比使用原始均分计算，显示均分与 Web 四舍五入口径一致。 |
| AI 显示完成但报告为空 | 实际调用得到空报告后补充非空正文校验、一次格式纠正重试和截断检测；显式控制 DeepSeek 思考模式，增大输出额度。格式失败、超出工具循环上限均返回失败，不再伪装成功。 |
| AI 部署服务不完整或假可用 | Ubuntu 包补入 Python 侧车，排除 `.env` 和虚拟环境；支持部署目录及虚拟环境解释器查找。自动启动时为 Node/Python 建立内部通信密钥，已有配置优先。可用状态同时检查侧车、数据库和内部鉴权。 |
| 远端只收图片，未完成判分入库 | Windows 调用真实原生识别器，上传识别结果和图块；Linux 根据服务端答题卡答案重新判分并持久化，更新排名、完整性和会话状态。重复完成请求保持幂等。 |
| 本机持久化失败可能被忽略 | 将本机成绩写入作为等待步骤，成功后再更新结果缓存。 |
| 双面背面无学号导致上传失败 | 仅继承当前任务中紧邻且已成功上传正面的学号；孤立背面不能继承其他任务的学生。增加回归。 |
| 共享答题卡的考试归属不明确 | 没有进行中考试或关联多个进行中考试时，返回可读冲突提示，避免静默把成绩和图块绑定到任意考试。 |
| 网阅保存批注报 500 | 接口原来写入两个数据库模式都不存在的位置、尺寸和颜色列；改为存入已有 `data_json`，与读取及绘制契约一致。验证保存、读回坐标与文本、删除。 |
| 新增识别响应临时图块残留 | 图块编码到响应后清理该请求创建的临时目录，不删除持久化图块。 |
| 全新 MariaDB 初始化出现缺表日志 | 将 MariaDB 建表提前到依赖表的数据迁移之前。 |

## 已通过的业务链路

1. 创建和编辑答题卡 → 保存 → 读取布局 → 导出 PDF → 同步到本机扫描端。
2. 创建年级、班级、学生、考试、应考名单 → 填涂图片 → 本机原生 OMR → 上传原图、识别结果、图块 → 服务端重新判分 → 分数入库。
3. 重复提交完成请求 → 会话已识别数量正确 → 名单齐全后结考。
4. 单科概况、成绩、题目分析、分布、指标、班级对比、选项分析、可比较考试；大考概况、指标、题目、分布、班级、排名；跨考总分。
5. 手动改分 → 并列排名 → 分析缓存刷新 → 恢复原分 → 公布 → CSV 导出 → 学生登录、成绩详情、趋势、学科对比。
6. 真实浏览器配置扫描服务器 → 同步选卡 → 导入四张图片 → 点击“本地判分+上传服务器” → 核对远端实际分数与考试完成状态。
7. 真实浏览器打开七个分析页签，复测此前图表崩溃；打开总体分析并检查实际图表；保存全局设置并出现成功提示。
8. AI 七个工具在 MariaDB 上执行；真实服务商生成任务完成且正文非空；从网页“生成分析”按钮发起并等待最终报告显示。
9. 远端网阅图块可见 → 保存、读取、清除断点续批草稿 → 批注保存、读回、删除 → MariaDB 备份 ZIP 导出。

补充回归：上传成功、断线恢复、失败页补传、双面学号继承；主观题 scoreGrid、lineGrid、essayGrid、批注配置往返（23 项）；网阅提交（3 项）；试卷池（19 项）；三态评分模式（6 场景）；分析阈值（26 项）；阅卷规则、原生布局、跨方言 UPSERT/聚合、侧车定位等已有针对性验证。未运行网络安全测试套件。

# 25 考生搜索绕过教师学生列表范围

- 原标题：Participant search bypasses teacher student-list scope
- 云端级别：Medium
- 原始报告：[打开报告](https://chatgpt.com/codex/cloud/security/findings/70ed04f7151c8191bacb370fd84b2fd6?repo=https%3A%2F%2Fgithub.com%2FDalian-No-5-Middle-School-I-T-C%2FProject-X&sev=&page=2)
- 关联提交：[7069716](https://github.com/Dalian-No-5-Middle-School-I-T-C/Project-X/commit/70697163f9c456677f8ad4499b65b832e9032810)

## 概要

本提交新增 GET /api/exams/:examId/participant-search 和全局搜索助手。路由有 requireExamAccess 及 GRADE_READ，却未用同类学生搜索既有的 makeViewPermissionGate("can_view_students")。searchStudentsForExam 把参数命名为 _examId 并完全忽略，查询所有活跃学生账号，不关联考试、名册、班级、年级、教师分配或权限矩阵。

普通教师只要能访问任意考试，就可按学号前缀／姓名片段查其他班级年级的稳定 ID、姓名、学号。每次 LIMIT 20 不防重复前缀枚举。对照的既有 student-search 同时检查 can_view_students 并仅查该考试已入分学生。

## 验证、证据与攻击路径

真实默认认证 Express 测试中，普通教师对新接口返回 200 和 20 条越范围记录，两次前缀搜索枚举全部 25 名外部学生；对照受保护搜索为 403，不可访问考试也是 403。参数化 SQL 和转义 LIKE 防注入／单纯通配符倾倒，却没有对象范围。

教师选可访问考试 → EXAM_READ、requireExamAccess、GRADE_READ 通过 → 缺学生列表门禁 → 忽略 examId 的全体活跃学生查询 → 每次 20 条跨班级／年级身份。

## 分级与前提

发生可能性高：默认教师读取能力、正常 GET、简单前缀，无管理员或主机权限。影响程度中：可枚举校内身份目录，可能全校，但不含成绩、密码、答案图或秘密，且不写数据。按中影响×高可能性为中危。

前提为多班／多年级活跃学生、合格教师、任意未删除可访问考试、非空匹配 q、学校服务可达。默认认证、强制改密门禁、EXAM_READ、考试及软删除检查、GRADE_READ、活跃学生过滤、参数绑定／LIKE 转义和 20 条限制存在，缺精细学生权限和枚举限流。

## 盲点

SQLite 动态验证，MariaDB 未跑；实际公网或内网暴露、目录规模和敏感性未知。文档确有管理员跨班／跨年级名册用途，候选搜索广度应明确，但无法解释普通教师绕过 can_view_students=0。未查看生产审计或真实学校数据。

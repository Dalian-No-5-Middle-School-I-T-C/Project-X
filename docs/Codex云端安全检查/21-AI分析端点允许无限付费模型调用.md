# 21 AI分析端点允许无限付费模型调用

- 原标题：AI analysis endpoint permits unbounded paid model requests
- 云端级别：High
- 原始报告：[打开报告](https://chatgpt.com/codex/cloud/security/findings/d7bac34ad0408191ac567a9db806fb00?repo=https%3A%2F%2Fgithub.com%2FDalian-No-5-Middle-School-I-T-C%2FProject-X&sev=&page=2)
- 关联提交：[8047a45](https://github.com/Dalian-No-5-Middle-School-I-T-C/Project-X/commit/8047a4502c580d03a83c17fca547c83499ef200c)

## 概要

本提交新增付费 AI 分析及提供商循环，Node 与 Python 两层都无滥用控制。POST /api/analysis/exams/:examId/ai-analysis 仅有默认教师都具备的 grade:read，接受已配置模型选择，检查考试存在和 classId 格式后转发，等待最多 120 秒。辅助服务同步执行最多 8 轮，每轮 max_tokens=4096、reasoning_effort=high，模型目录含 pro 模型。无逐用户限频、全局并发、去重、队列上限、冷却或预算。若兼容 PROJECTX_AUTH_ENFORCE 关闭，甚至无需认证，但原评级不依赖这一较弱设置。

原报告建议逐用户和实例配额、小型全局并发队列、提供商费用／令牌预算、取消、审计，以及独立 AI 调用权限而非通用成绩读取权。

## 验证及证据

真实 Express 认证／门禁／代理及 FastAPI 端点，只替换付费提供商操作：匿名在认证开启时被拒，普通教师 45 并发请求全部接纳，均转发 gpt-5.5-pro；观察到 40 个同步工作线程同时运行，剩余排队。另以模拟 SDK 执行真实循环，得到 8 次调用、各 4096 输出上限和 high 推理。共享线程饱和已证明，未联系真实提供商或产生费用。

## 攻击路径与分级

普通教师并发 POST → grade:read 通过 → 每请求独立 120 秒转发 → /analysis/run 同步提供商循环 → 全部工作线程占满及队列增长 → 学校配额／费用和 AI 可用性受损。

发生可能性高：正常教师、有效考试及简单请求，没有竞态、管理员或秘密提取要求。影响程度高：共享容量被占用、每请求可能放大八次费用，不是自身影响。运行时 40 线程上限只是排队而非拒绝；内部密钥由可信 Node 跨越，超时不限制准入和花费。需启用集成，限单实例 AI 与提供商资源，未证明接管、改分或窃密，故高危。

## 假设、控制与盲点

辅助服务运行、能访问数据库、至少一个已配置且可计费提供商、有效考试；保守场景认证开启，攻击者有 grade:read；学校入口可达。金钱影响还取决于模型被接受、实际输出及账单。

现有控制有认证开关、可选内部 Bearer、回环绑定、未知模型／无密钥／无数据库拒绝、120 秒 fetch 取消、观察到的 40 同步线程上限；报告按设计使用汇总成绩而非学生姓名。没有应用级队列额度、预算或 AI 专属权限。

具体公网入口、实际价格／信用限额／提供商限流与延迟未验证。40 线程数随 AnyIO/FastAPI/Python 配置而变；Express 取消是否停止底层 SDK 未确立；8 轮要求模型持续工具调用，正常请求可能更早结束。

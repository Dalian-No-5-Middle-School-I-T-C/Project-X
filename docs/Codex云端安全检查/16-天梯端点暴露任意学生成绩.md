# 16 天梯端点暴露任意学生成绩

- 原标题：Ladder endpoints expose arbitrary students' scores
- 云端级别：High
- 原始报告：[打开报告](https://chatgpt.com/codex/cloud/security/findings/906b3e28aa80819184af341b10ab2378?repo=https%3A%2F%2Fgithub.com%2FDalian-No-5-Middle-School-I-T-C%2FProject-X&sev=)
- 关联提交：[cf09692](https://github.com/Dalian-No-5-Middle-School-I-T-C/Project-X/commit/cf09692d1df1d604cb51ae509954ca28ce2b8293)

## 概要

本提交新增并挂载 /api/ladder，位置在既有考试／分析 RBAC 门禁前。正常分析分数表有 grade:read 和 requireExamAccess，新路由仅要求有效会话和全局功能开启，因而绕过这些限制。

学生可用任意考试 ID 调用 getScoreTableData(examId, undefined, ...)，undefined 班级范围会选择整场考试；无需同年级、参考或阅卷完成。前十响应含内部 ID、学号、真实姓名、班级、年级、精确分数和排名。考试组还泄露分科分；跨考接受任意考试列表、组或日期区间，未传原分析路径的 visibleExamIds。即使同年级榜单是设计行为，也应从学生身份派生年级并执行参考／发布条件，教师应有 grade:read 及考试范围。

## 验证及证据

真实路由、中间件、仓储和 SQLite HTTP 验证覆盖三种入口。Attacker Grade 的非参考学生对 grading 状态考试取得 200，读到两名 Victim Grade 学生身份和精确分数。匿名、功能关闭、本人查分以及受 grade:read 保护路径的负对照正确失败，说明不是关闭认证造成。

证据链为门禁前挂载、仅身份和功能开关、无班级限定的单考查询、无范围的组 SQL、包含身份及分科成绩的响应、未传授权可见集合的跨考查询。

## 攻击路径与分级

只有 score:read 的学生 → 任意 examId/groupId/examIds/日期 → 默认开关和认证通过 → 不带年级／考试授权范围的查询 → 返回未授权考试前十人的精确记录。

发生可能性高：默认迁移 v9 开启、普通 GET、无需竞态或受害者交互，三条路径都已复现。影响程度高：跨年级、跨发布边界的可识别成绩泄露，任意列表和日期支持重复收集。测试指南确有“学生年级前十、非参考者无个人排名”的预期，但不等于允许跨年级或未完成成绩。每次前十、只读、无接管／RCE／一次整库导出或成绩破坏，故高危。

## 假设、已有控制和盲点

有效普通学生会话，天梯开启，目标有成绩，ID 可选／枚举或日期包含目标，生产认证开启，按威胁模型通过代理／隧道远程可达。authMiddleware 拒无效会话，只有管理员能改开关，关闭后拒非管理员；每个范围最多十人。既有分析门禁不包裹天梯，缺角色／年级／班级／参考／发布授权及通用限流。

完整 createApp 因缺 expr-eval 未执行，PoC 挂载确切生产模块。仓库未给出具体隧道域名、TLS／网络策略，实际入口未知。政策未精确定义非参考者、精确成绩展示和发布状态，但跨年级、阅卷中泄露违反提供的威胁模型。单考 rank/gradeRank 映射缺陷使总排名字段缺失、百分位为 null，缩小这些字段影响但不阻止身份、精确分、班排名和年级泄露。UI 获取 ID 的方式未证明，整数枚举技术上可行。

# 16 天梯端点暴露任意学生成绩

- 原标题：Ladder endpoints expose arbitrary students' scores

## 概要

本提交新增脆弱 /api/ladder 路由，并挂载在已有分析授权路径之外。已有成绩表分析使用分析权限门禁及 requireExamAccess，新路由仅要求有效会话，绕过这些控制。

所有天梯路由只受 authMiddleware 保护，功能开启检查不是对象范围授权。路由在考试/分析 RBAC 门禁之前挂载，不受其保护。因此任何认证学生都能 GET 任意顺序 examId，即使未参考、属于其他年级或仍在判分。端点调用 getScoreTableData(examId, undefined, ...)，undefined 班级范围会选择整场成绩，返回前十内部 ID、学号、实名、班级、年级、精确成绩和排名。组端点同样查全部成员考试所有分数，不检查组年级或调用者关系，并返回精确分科分。跨考接受自选考试列表、组或任意日期范围，调用 getCrossExamTotal 时不传已有分析路由使用的 visibleExamIds。由此可规模枚举考试，披露未发布/范围外教育记录。即使同年级榜单是预期，API 也必须从身份派生并强制学生年级、参考和适当发布/关闭状态；非学生访问应执行现有教师考试范围及 grade:read。

## 验证

1. 确认生产挂载，天梯开启时正常学生会话可达。
2. 确认挂载到三个数据处理器之间无角色、grade:read、考试范围、参考或发布控制，最近控制为功能开关。
3. 自选考试、组、日期/列表进入广义成绩查询，无授权可见考试、班级、年级约束。
4. 响应披露仍判分考试中其他年级学生可识别精确分数和排名。
5. 使用真实受影响路由、认证/会话、权限中间件、仓储、隔离库，通过本地 HTTP 专项请求及负面对照复现。

## 证据注释

1. 路由挂载在考试/分析门禁前，不继承 grade:read、exam:read 或对应范围授权。
2. undefined 班级范围使仓储加载所选考试全部可识别成绩。
3. 除认证只有全局开关，无角色、权限、年级、班级、参考、考试可见性或发布状态。
4. 自选考试 ID 未经授权进入整场成绩表查询并返回前十。
5. 组榜直接选择全部成员考试的学生身份/成绩，无调用者年级或授权考试过滤。
6. 组响应披露学生 ID、学号、姓名、班级/年级、精确总分、排名与分科分。
7. 跨考接受可控考试 ID、组和日期，未传授权可见考试集合即查询返回排名。

## 攻击路径分析

不适用强制排除：非本人影响、前提现实、低权限学生而非管理员/操作者，且属于真实运行流程。跨年级披露可识别、精确且可能未发布成绩，可规模选择考试/日期，影响高。有效学生、默认开启功能、简单远程 GET 即可，可能性高。矩阵为高影响加高可能性，但不应严重：仅机密性，每响应前十，无管理员接管、代码执行、整库提取或成绩完整性破坏。保留原高危。

### 路径

只有 score:read 的学生 → 提供 examId/groupId/examIds/日期 → 自控单考/组/跨考请求 → 有效会话通过 authMiddleware，默认开关通过 checkLadderOpen → 缺分析 RBAC/考试范围 → 仓储/SQL 无授权年级考试范围 → 成绩查询联结身份、班级、年级、分数 → 序列化精确字段 → 返回未授权考试前十教育记录。

攻击过程：学生正常登录，猜/选整数考试或组 ID，请求天梯。有效会话加默认开启后查全部范围成绩，从不验证参考、目标年级、考试可见或判分结束。真实路由、中间件、仓储、SQLite HTTP 验证显示：Attacker Grade 的未参考学生通过三个接口都获 200，含 grading 考试中两名 Victim Grade 学生身份和精确分数。未认证、功能关闭、自身成绩、grade:read 保护的负面对照均正确失败。最强反向证据为测试指南有意定义学生年级前十，并允许未参考者没有个人排名；这支持同年级榜单意图，却不支持跨年级或未发布泄露。单范围前十限制不能消除任意 ID、列表、组、日期重复收集的规模性。因此是机密性授权漏洞，不是排名正确性问题。

## 发生可能性

**高。** 只需普通学生会话与 GET，默认开启，调用者提供整数，无交互/竞态。三个变体及效果均已复现，负面对照确认原因是缺授权而非认证关闭。对威胁模型代理/隧道生产部署，可能性高；直接回环及无入口清单是剩余部署不确定性。**攻击向量：远程网络。**

## 影响程度

**高。** 跨年级和发布边界披露实名、学号、内部 ID、班级/年级、精确分数与排名，组模式另有精确分科结果。自选 ID/日期可跨考试重复收集。符合学生广泛获取未发布成绩的高影响场景，但不改分、接管账号或单请求披露整库。

## 假设条件

- 有有效普通学生账号及 Bearer/Cookie，无需教师/管理员。
- 天梯启用，迁移 v9 默认开启，管理员可关。
- 至少一目标考试/组有成绩，攻击者可选/枚举整数 ID 或覆盖它的日期范围。
- 远程依据威胁模型代理/Cloudflare 公开回环服务，仓库无精确入口清单。
- 生产按威胁模型保持认证开启。

原文另列前提：

- 有效低权限学生会话。
- 天梯开启。
- 目标考试/组有成绩。
- 知道/枚举考试 ID、组 ID、考试列表或日期范围。

## 控制措施

- authMiddleware 拒缺失/无效会话。
- ladder_enabled 可阻止非管理员访问。
- 改开关仅管理员。
- 每请求范围最多前十。
- 既有分析路由有 grade:read/考试可见性，但不包裹天梯。
- 天梯无角色、年级、班级、参考、考试可见或发布授权。
- 无通用 API 限流限制 ID/日期重复枚举。

## 盲点

- Node 直接 localhost，无已检入清单证明外部代理、隧道域名、TLS 端口或策略，远程依给定威胁模型。
- 缺 expr-eval，未执行完整 createApp，PoC 经本地 HTTP 挂载精确受影响路由、中间件、仓储、库。
- 文档确立学生年级榜意图，但不明确未参考、精确分数展示、发布状态是否获政策批准；跨年级及判分中披露仍违反给定模型。
- 单考响应有 rank/gradeRank 映射错误，遗漏总排名并产生 null 百分位，缩小这些字段，却不阻止身份、精确分、班排名或年级披露。
- 未证明学生如何从 UI 发现 ID，但直接接受整数且技术上可反复枚举。

router.get("/cross-exam", async (req: Request, res: Response) => {
  if (!checkLadderOpen(req, res)) return;
  try {
    const { mode, examIds, groupId, startDate, endDate } = req.query;

    const request: any = { mode: mode || "week" };
    if (mode === "selected" && examIds) {
      request.examIds = String(examIds)
        .split(",")
        .map((s) => Number(s.trim()))
        .filter((n) => Number.isFinite(n));
    }
    if (mode === "group" && groupId) {
      request.groupId = Number(groupId);
    }
    if (startDate) request.startDate = String(startDate);
    if (endDate) request.endDate = String(endDate);

    const analysisRepo = new AnalysisRepository();
    const crossExamData = await analysisRepo.getCrossExamTotal(request);

    if (!crossExamData || crossExamData.rows.length === 0) {
      const resp: LadderResponse = {
        scope: "cross",
        scopeName: "跨考累计",
        studentCount: 0,
        myRank: null,
        myScore: null,
        rows: [],
      };
      res.json(resp);
      return;
    }

    const { top10, myRank, myScore } = LadderService.fromCrossExamRows(
      crossExamData.rows,
      crossExamData.rows.length,
      req.user!.id,
    );

    const resp: LadderResponse = {
      scope: "cross",
      scopeName: "跨考累计",
      studentCount: crossExamData.rows.length,
      myRank,
      myScore,
      rows: top10,
    };
    res.json(resp);

# 22 无上限阅卷进度流可耗尽连接

- 原标题：Unbounded grading-progress streams enable connection exhaustion
- 云端级别：High
- 原始报告：[打开报告](https://chatgpt.com/codex/cloud/security/findings/5d70c9da295481918386529b3c38c3fd?repo=https%3A%2F%2Fgithub.com%2FDalian-No-5-Middle-School-I-T-C%2FProject-X&sev=&page=2)
- 关联提交：[f3560f9](https://github.com/Dalian-No-5-Middle-School-I-T-C/Project-X/commit/f3560f9aabdacccb48dd6f80d234c343b3d35c39)

## 概要

本提交新增进度监听全局映射与无限期 SSE 路由 GET /api/cards/:cardId/grading/progress/:batchId。它不检查卡片存在、批次活跃或归属，cardId 实际未用。任意 batchId 都可登记捕获 Express response 的闭包；不存在的任务永远不会发 done/error，服务端也无超时或额度，只有客户端断开才清理。

默认 card:read 教师可对 nonexistent/unique-N 反复开流并保持连接，消耗 Node／反代 socket、文件描述符和堆。历史默认不强制认证时也可匿名。原报告建议只接受服务端创建且绑定用户和卡片的活跃任务，拒未知任务，限制每用户／IP 流数量并设置空闲与绝对寿命。

## 验证及证据

认证开启、普通教师令牌的真实 HTTP 测试保持 2000 个未知 ID 连接 15 秒，服务描述符恰增 2000，RSS 约增 59 MiB，全都直到客户端释放才关闭；断开后描述符回基线。普通请求仍快速完成，未制造完整停机。源码证明全局映射保留闭包和 response，无作业校验、数量上限、超时。

## 攻击路径与分级

远程普通教师／兼容模式匿名 → 任意 ID 的 SSE → 通用 card:read → 全局监听映射持有 response → 攻击者控制断开时刻 → 线性消耗共享服务和代理资源。

发生可能性高：普通 GET、任意标识，无竞态，2000 条实际稳定保留；需要维持大量连接。影响程度高：达到部署阈值后可阻断其他扫描、阅卷、考试和分析。非读取者自身资源，普通读权限越到共享进程资源控制。可用性限定、测试未强制停机且实际阈值未知，故高危而非严重。

## 假设、控制与盲点

共享服务经威胁模型中的代理／隧道可达；认证开启时账号有 card:read；上游允许足够多连接；攻击者可长期保持 TCP。默认兼容模式无需身份。

optionalAuth 解析 Bearer／查询令牌；强制模式有 401/403；safeId 仅清理字符；done/error 删除对应集合；req close 删除单监听和空集合；终态快照 60 秒后删除；Node 回环监听。这些不限制永不创建任务的活流。

未确认真实反代的连接限额、超时、缓冲、按 IP 策略，以及主机文件描述符、容器内存和 Node 设置。测试在回环，未测反代额外资源或更早限额。没有在 2000 连接时证明完整拒绝服务。仅 Electron 本地临时服务部署可能只产生本地／自身影响，不能直接套远程评级。

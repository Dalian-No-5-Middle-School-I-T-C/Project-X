# 40 已知初始化密码允许取得管理员身份

- 原标题：Known bootstrap password enables administrator account takeover
- 云端级别：Low
- 原始报告：[打开报告](https://chatgpt.com/codex/cloud/security/findings/655cb18f92548191affa125ebb8a62c7?repo=https%3A%2F%2Fgithub.com%2FDalian-No-5-Middle-School-I-T-C%2FProject-X&sev=&page=2)
- 关联提交：[313f2fb](https://github.com/Dalian-No-5-Middle-School-I-T-C/Project-X/commit/313f2fb0d231f7af79921596814806ac5c36058c)

## 概要

本提交自动创建活跃 admin/admin123 并挂载 /api/auth/login；公开已知凭据可换八小时 Bearer、role 1 通配符身份。没有随机初始化秘密、强制改密状态或改密路由，密码只能通过外部数据库操作替换。原始概述提出管理员接管风险并建议随机每实例秘密、受保护传递和首次改密后再给完整会话。

但原报告复核后明确下调：此精确版本 authMiddleware、requireRole 只定义而未挂载，/api/auth/me 也因 req.user 未设置返回 401，没有证明任何受保护特权消费者。卡片和扫描路由本就无认证，不能把它们的权限算成该令牌带来的接管后果。

## 验证及证据

真实 HTTP 证明新库固定管理员、bcrypt 校验成功、八小时随机令牌和管理员用户对象／通配符角色。只证明身份跃迁、令牌签发和 last-login 更新；没有令牌可用的特权 API。直接服务监听 127.0.0.1，README 只写本地，精确提交无代理／隧道配置。PoC 因缺原生 bcrypt 用兼容 bcryptjs，其余初始化、路由、身份和令牌是仓库实现。

## 攻击路径与分级

本地或外部转发可达匿名调用者 → 固定密码登录 → 管理员标记的内存令牌 → 链条到此停止，没有已挂载的特权令牌消费者。

原严重判断假设公网和立即可用管理员权限，这两点均无该版本证据。发生可能性低：默认回环，外部转发只是整体威胁模型中的可能。实际影响低：没有证明超出管理员标签和会话状态的权能。故低×低调整为低危；仍保留真实认证工作流的固定凭据缺陷，不能宣称此版本已实现完整实例接管。

## 假设、控制与盲点

应用运行，新／恢复库没有 admin 行，密码未外部替换，攻击者可达回环或运维转发。现有 admin 则不新建；bcrypt cost 10、通用错误、活跃状态、32 字节随机令牌及八小时到期、Electron 临时回环端口与隔离／沙箱有效；无登录限流和强制改密。

仓库外转发未知；无其他消费同内存令牌的下游服务证据；运维是否在公开前改库未知。其他路由未认证是另一个问题，不归到本项链条。

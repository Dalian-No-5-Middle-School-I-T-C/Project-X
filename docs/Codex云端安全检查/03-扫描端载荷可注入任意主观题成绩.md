# 03 扫描端载荷可注入任意主观题成绩

- 原标题：Scanner payload can inject arbitrary subjective scores
- 云端级别：High
- 原始报告：[打开报告](https://chatgpt.com/codex/cloud/security/findings/a8d0c566afc8819187ec02f8260b6bc6?repo=https%3A%2F%2Fgithub.com%2FDalian-No-5-Middle-School-I-T-C%2FProject-X&sev=)
- 关联提交：[96dc520](https://github.com/Dalian-No-5-Middle-School-I-T-C/Project-X/commit/96dc520d9008ea606e1424cc2a5c8551ee9ae810)

## 概要

本提交新增长期保存远程客户端识别结果并自动入分；此前远程接口只上传图像。新 Zod schema 仅要求主观题得分和满分为有限、非负数，不要求 questionId 或 questionNumber 属于所选答题卡。载荷原样保存后交给 gradeSessionStudentResults。客观题会按权威卡片重新判分，但 gradeSubjectiveRecognition 遇到未知 questionId 时回退采用客户端 maxScore，并将客户端得分计入总分。伪造总分及虚构逐题记录最终写入 student_scores、question_scores。

持扫描密钥的攻击者可为关联唯一活跃考试的答题卡创建会话，上传有效图像和虚构题目，再完成会话，覆盖名册内学生成绩。具有 GRADE_WRITE 和足够考试范围的教师也有替代入口。原报告建议拒绝卡片外题目，仅从卡片派生题号与满分，校验唯一性及权威题目覆盖，禁止客户端满分回退。

## 验证

真实 HTTP PoC 验证识别输入未绑定卡片题目身份／题号／满分；未知题目采用客户端分数和满分；完成会话后写入伪造总分与题目。攻击载荷使用 invented-question-id、FORGED-999，score=maxScore=777777；权威卡片只有另一道满分 10 的题，仍返回完成状态 200 并入库 777777。认证、考试解析、学生名册、完整页、重复及会话检查均满足，却未阻断此链条。

## 证据说明

识别 schema 接受任意主观题 ID 和分值；数组原样序列化进 twain_recognition_results；读取后未经权威主观题覆盖校验直接判分；未知题目用攻击者 maxScore 限制攻击者 score；汇总与虚构题目随后在持久化事务中落库。

## 攻击路径与分级

恶意／失陷扫描端持 X-Api-Key → 创建会话并上传图像及伪造主观题 → 形状校验后原样保存 → gradeSessionStudentResults／gradeSubjectiveRecognition → 未知题目采用客户端满分 → upsert 总分及逐题记录。

这是从“可提交 OCR 结果”越界到“可定义权威题目和满分”，并非正常扫描服务权限。发生可能性高：启用正常远程工作流并持 scanner/full 密钥后，远程、低复杂度、无需竞态或受害者交互，已端到端复现。影响程度高：可改写他人的权威总分和逐题记录，影响排名重算和分析，并可重复作用于其他可达学生／考试。需要有效凭据，未证明代码执行、保密性泄露或管理员接管，故定为高危而非严重；不适用仅自身或运维专属等排除条件。

## 假设条件

PROJECTX_ENABLE_SCANNER_CLIENT_API=1；攻击者合法持有或已窃得 scanner/full 密钥，本报告不主张已证明密钥窃取方式；答题卡唯一对应符合条件的活跃考试；学号对应现有学生且满足适用名册限制；图像、上传令牌、全部页面及各页识别数据完整。教师替代路径要求 GRADE_WRITE、考试访问和整卡阅卷范围，但未动态验证。

## 已有控制

远程接口默认关闭；Node 回环绑定，远程需代理／隧道。dualAuth 校验 scanner/full 密钥或 GRADE_WRITE 用户；密钥检查活跃状态和范围，新密钥以 SHA-256 保存；教师路径检查考试及整卡范围；上传令牌须属当前会话，图像须通过魔数校验；完成会话要求全部页面、识别数据及唯一考试；写入要求学生存在并遵守已知名册；成绩写入使用事务。这些都不校验主观题身份、权威题号／满分、唯一性与覆盖。

## 盲点

不确定具体部署是否启用远程接口或公开端口。PoC 使用 SQLite；共享判分逻辑与数据库无关，但 MariaDB 持久化未单独执行。教师入口未动态复现。没有独立的密钥获取或工作站攻陷链。示例每会话证明一名学生入库，大规模利用需重复正常扫描流程。

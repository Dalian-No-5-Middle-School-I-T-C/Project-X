# 01 固定初始化密码可导致远程管理员接管

- 原标题：Fixed bootstrap password enables remote administrator takeover
- 云端级别：Critical
- 原始报告：[打开报告](https://chatgpt.com/codex/cloud/security/findings/98d48d32ed248191afb4289b16f8a974?repo=https%3A%2F%2Fgithub.com%2FDalian-No-5-Middle-School-I-T-C%2FProject-X&sev=critical)
- 关联提交：[7103440](https://github.com/Dalian-No-5-Middle-School-I-T-C/Project-X/commit/7103440c483faab2974db72d8c3a29cdf366376b)

## 概要

本提交引入此问题。此前，新管理员使用密码学安全的随机 24 字节 base64url 密码，旧的 admin123 也会自动轮换为随机值。本提交改为公开且固定的 admin123，并在启动时把所有仍处于强制改密状态的现有管理员——包括此前使用随机初始化密码的安装——重置为该密码。SQLite 和 MariaDB 分支均如此。

未认证网络攻击者只需用 admin/admin123 登录，再以 admin123 为旧密码设置自己的新密码。强制改密门禁只拦截普通业务 API；认证与改密路由位于门禁之前，因此无法阻止接管。首次就正确的登录也不受错误尝试限流保护。Node 虽监听回环地址，但文档支持的反向代理／隧道使公开初始化或恢复窗口可以远程利用。成功后可控制用户、凭据、考试、成绩、学生记录、备份及系统设置。

## 验证

云端报告确认：生产近似环境下全新 SQLite 初始化生成固定密码且哈希验证成功；未认证请求取得管理员会话；强制改密会话可调用真实改密路由并清除标记；重新登录后可访问管理员专属 /api/users。仓库的 Cloudflare Tunnel 和 Nginx 指南用于确认合理网络入口及前提。

## 证据说明

认证路由先于强制改密门禁挂载；BOOTSTRAP_ADMIN_PASSWORD 被定义为固定已知值；启动时重置仍需改密的管理员；两种数据库创建管理员时都使用它。公开登录接口接受该凭据并生成 Cookie 或 Bearer 令牌。AuthService 验证旧密码后更新新哈希、清除强制改密标志，攻击者重登即可获得完整权限。

## 攻击路径与分级

未认证攻击者 → 公开反向代理／Cloudflare 隧道 → 回环 5174 端口的 POST /api/auth/login → 带强制改密标记的管理员会话 → 门禁前 POST /api/auth/change-password → 攻击者控制的新凭据 → 重登后取得通配符管理员权限。

可执行 PoC 通过真实 Express createApp() 完成上述链条。普通 API 在改密前返回 428，但不妨碍先改密。bcrypt 哈希、0600 文件权限不能抵消密码本身公开且固定的问题。影响不只限于攻击者自身；无需既有账号、开发者权限、物理访问或受保护路径写入，也不存在应强制排除的条件。发生可能性为高：对受影响状态，只需第一次正确请求且无需受害者交互。影响程度为高：从匿名跃迁到管理员，破坏教育数据的保密性、完整性和可用性。依原报告矩阵，因满足“未认证管理员接管”标准，最终为严重。

## 假设条件

目标是新部署、恢复部署，或管理员仍有 password_change_required=1 的部署；攻击者可在合法管理员首次改密前到达本机 API 或公开代理／隧道；代码对应报告关联提交。SQLite 有动态验证，MariaDB 等价性仅经静态确认。

## 已有控制

密码以 bcrypt 保存；支持的平台上初始化文件权限为 0600；15 分钟内每账号 10 次、每 IP 60 次登录限制；会话令牌随机且不透明；浏览器 Cookie 设置 HttpOnly、SameSite=Lax；强制改密时普通 API 被阻止；改密撤销其他会话。password_change_required=0 的现有管理员不重置。Node 仅绑定 127.0.0.1，下游管理路由也检查认证和权限，但被接管的身份具有通配符权限。

## 盲点

仓库只能证明支持公开入口，不能证明某个真实实例当前暴露。随机 Cloudflare 隧道域名未公开，因此未证明攻击者如何发现特定隧道。MariaDB 未动态验证。PoC 证明接管及读取管理员用户列表，没有破坏性调用所有管理操作。已完成初始化且标记为 0 的管理员不受该路径影响。

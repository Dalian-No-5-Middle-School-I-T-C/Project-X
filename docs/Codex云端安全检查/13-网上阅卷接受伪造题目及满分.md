# 13 网上阅卷接受伪造题目及满分

- 原标题：Online review accepts forged questions and maximum scores
- 云端级别：High
- 原始报告：[打开报告](https://chatgpt.com/codex/cloud/security/findings/f45c24455e4c8191a59e9e62be86db0d?repo=https%3A%2F%2Fgithub.com%2FDalian-No-5-Middle-School-I-T-C%2FProject-X&sev=)
- 关联提交：[615f738](https://github.com/Dalian-No-5-Middle-School-I-T-C/Project-X/commit/615f73894d0365367b5bfa01dfdc07df12b8de55)

## 概要

本提交新增 POST /api/review/exams/:examId/block-crops/:cropId/submit 和 ReviewService。路由只检查 scores 是非空数组，将对象直接传入服务。服务虽核对裁图所属考试并加载卡片，却不验证 questionNumber 是否在裁图 question_numbers、属于题块或存在于卡片；scoreType 也可信任。客户端 maxScore 优先于卡片，未知题目甚至用提交 score 自身作为满分。

例如题号 999999、subjective、score=maxScore=1000000 可插入虚构满分题。score_type 参与 upsert 唯一键，任意类型又能为同一题插入平行记录。所有行计入学生总分并重算全考试排名。原报告要求从裁图及权威题块派生题目、类型和满分，拒绝未知／重复题目及非有限数值，写入前强制题块权限。

## 验证与证据

真实认证 HTTP、普通 subject_teacher、正常队列取得裁图 ID后提交，返回 200；插入百万分虚构题和一个自定义类型的题 1 记录，将学生从总分 5／排名 2 变成总分 1000505／排名 1。检查覆盖请求体缺少成员、类型、界限、重复和有限数值校验；数据库允许虚构题和多类型行；审计能记录但不能阻止。

## 攻击路径与分级

正常教师会话 → 可访问考试的队列提供裁图 ID → 伪造 scores JSON → 非空数组检查 → ReviewService 信任题号、类型、得分与满分 → question_scores upsert → student_scores 汇总及排名更新。

发生可能性高：普通 JSON、默认权限、无需竞态或受害者交互。影响程度高：可虚构权威题目／分值并改变同考学生排名，队列使重复操作可行。教师本可改已有成绩，但新增虚构题、类型、满分越过权威裁图边界。需要认证、考试可见性和既有裁图，且审计可追踪，未证明跨考试、账号接管、RCE 或泄密，故高危。

## 假设、控制与盲点

生产认证开启；教师有 grade:read、grade:write 和目标考试可见性；考试关联有效卡片，裁图关联学生；可通过支持的 HTTPS Nginx 访问回环服务。

requirePermission 拒匿名，requireExamAccess 限班级／学科，服务检查裁图属于考试、存在学生与卡片，写分和总分使用事务。名义分数钳制因满分可控而无效。manually_modified、answer_overrides 记录操作者。UI 正常只提交 current.questionNumbers 和推导类型，不能代替服务端校验。

SQLite 已动态验证，MariaDB 仅静态等价。未负载验证大规模重复或可用性，只证明一个学生总分及同考排名改变。本提交尚无分配／领取模型，不依赖越过指定阅卷者边界。另有手动改现有分接口，削弱本项独有的排名修改增量，但虚构题／类型／满分仍是独有效果。此端点改分是否自动撤回发布未确立，实际公网入口亦未知。

# 10 阅卷上传绕过考试范围授权

- 原标题：Grading upload bypasses exam-scope authorization
- 云端级别：High
- 原始报告：[打开报告](https://chatgpt.com/codex/cloud/security/findings/c51023c02c9c8191a6f302611d462bd5?repo=https%3A%2F%2Fgithub.com%2FDalian-No-5-Middle-School-I-T-C%2FProject-X&sev=)
- 关联提交：[1b0d370](https://github.com/Dalian-No-5-Middle-School-I-T-C/Project-X/commit/1b0d370ba5a81dfe3d8f1edfca158bc276d7fabc)

## 概要

本次回退提交删除阅卷上传入口的考试范围检查，引入授权回归。剩余 cardGate 只确认 GRADE_WRITE；validateExamIdsAccess 仍存在并正确实现范围校验，却不再于持久化前调用。基线会解析 examId 并对越权考试返回 403。

POST /api/cards/:cardId/grading 直接把 multipart body 的 examId 交给 persistGradingResults。后者仅验证考试及全局解析的学生存在，改变考试状态、创建扫描批次、upsert student_scores 和 question_scores；也不比较 URL 卡片与 exam.card_id。学科教师／班主任可把可识别图像写入范围外考试，覆盖多个学生成绩，并关闭该考试。

## 验证及证据

真实认证和 cardGate 链允许受限教师进入上传，而正常考试范围端点对同一目标返回 403。复现使用 attacker-card 处理关联 target-card 的考试，将范围外学生分数从 3 改为 10，写逐题分、创建完成批次并关闭考试。Express、multipart、仓储、事务及 SQLite 为真实生产实现；原生 OCR 被替换为确定性、契约兼容的成功识别器，因此证明的是识别成功后的授权与持久化绕过，不是恶意像素构造能力。

代码证据包含考试存在性检查后立即改状态／创建批次、全局学号解析、角色级卡片门禁、未检查的 body examId，以及被目标回退明确移除的 validateExamIdsAccess 调用。

## 攻击路径与分级

受限教师 → 普通 grade:write → URL 选择卡片并识别上传文件 → body 独立选择范围外考试 → 未校验 examId 的持久化 → 改总分、逐题分、批次和考试状态。

发生可能性高：正常第一方上传流程、默认教师权限，无受害者交互；教师也可上传普通有效答题卡后只改 examId，不必伪造复杂像素。影响程度高：跨学科／班级范围改变权威学业成绩及工作流。教师权限正是被绕过边界的较低身份，非管理员专属、仅自身或不可实现前提。仍需账号、目标标识及成功识别，影响在选定学校和考试内，未证明匿名全实例接管，故高危。

## 假设条件与已有控制

默认认证启用，攻击者已完成必要首次改密，有普通学科教师／班主任账号及 grade:write，知道范围外数值考试 ID、现有学号和有效卡片 ID；上传必须得到成功识别。报告的 internal_only 表示普通已认证校内人员，并非管理员专属。

身份与强制改密门禁有效；匿名 401、无权限 403，学生默认无 grade:write；getVisibleExamIds／validateExamIdsAccess 在调用它们的路由有效；CORS 允许列表不防直接认证 HTTP；识别单文件 20 MiB；按学生使用事务并检查对象存在。Node 回环监听可经文档 Cloudflare 隧道公开。登录限流不能限制已认证阅卷。

## 盲点

仅 SQLite 动态验证，MariaDB 未跑；OCR 替代使具体物理图像可控性未验证。真实部署入口、隐藏考试 ID 与学号发现难度未知；仓库未提供额外网络策略或身份感知代理配置。实际单请求可改多少学生取决于识别吞吐、请求处理和运行限制。本项不需要或暴露应用秘密。

## 概要

此问题由本次修改引入。此前总览使用五个固定区间及五次查询，不受满分影响。新的循环和逐区间查询，使成本正比于没有上限的数据库值。

提交用 generateDistributionRanges(fullScore) 替换五个桶。fullScore 来自 question_scores.max_score 求和；数据库结构、答题卡规范化及判分路径都不限制客观题分值。教师可设置巨大有限分值，给已识别学生判分使满分入库，再请求总览。十亿满分使同步处理在执行任何逐桶 COUNT 之前，先分配约一亿个对象，可能耗尽堆或阻塞事件循环，使全部 API 中断。恶意分值留在数据库中，重启后可以再次触发。客户端过滤在响应之后才发生，不能限制服务端工作。应验证并封顶各题分值及总满分，拒绝非有限数，设置固定最大桶数量，最好执行一次聚合 SQL，而不是逐桶查询。

## 验证

1. 确认已保存的 SUM(max_score) 是无界循环条件，产生 O(fullScore/10) 级分配和查询。
2. 非管理员教师可以访问答题卡和判分接口，提交过大的有限客观题分值并传播入库。
3. 总览虽然认证授权，但教师可以访问，并同步调用存在问题的仓储。
4. 通过最接近可行的生产接口及仓储框架，动态证明持久化大数值使已认证 HTTP 请求以堆耗尽终止服务。
5. 检查数据库结构、运行控制及持久性：没有分值上限，需要至少一名已判分学生，恶意值保留后又使重启进程再次崩溃。

## 攻击路径分析

不下调或排除。影响不只限于本人，已授权教师能够终止共享 API。攻击者不是管理员、运维、开发者或主机用户，所需只是正常生产默认教师权限；服务级可用性损害超出预期阅卷权限。前提现实，概念验证已实际执行。高影响及高发生可能性得到高危，没有达到严重：需要教师身份及判分条件，影响单个服务，造成可用性损失，而非管理员接管、广泛数据失陷、远程代码执行或隐蔽批量改分。

### 路径

已认证普通教师 → 使用默认 CARD_WRITE → PUT 答题卡，score=1000000000 → 规范化没有有限幅值限制 → 仓储保存 → 客观题判分复制 maxScore → 生产 INSERT 写入 q.maxScore → 题目成绩表保留恶意值 → SUM 得到 fullScore → 无上限地控制循环和查询数量 → 无界对象及逐桶 SQL → 堆耗尽，或事件循环／数据库阻塞 → Node 崩溃，共享 API 中断。

攻击过程：恶意或失陷教师正常修改答题卡，为客观题设置巨大有限分值。默认教师拥有答题卡及成绩读写权限，旧版无细分角色教师能看到全部考试。规范化不封顶，仓储保存，客观题判分复制满分，生产循环写入题目成绩。至少一名学生已判分后，获授权用户请求总览，先每 10 分建立 JavaScript 对象，再对每桶 COUNT。十亿分因此约产生一亿次分配。验证执行已认证答题卡写入路由、真实判分逻辑及持久化结构和已认证总览；总览使 V8 内存耗尽，持久化记录又使重启后能够再次触发。不涉及秘密，资产是共享可用性。最强反向证据为回环监听、受保护教师流程、专门教师受 requireExamAccess 限制，以及没有学生时提前返回。但文档支持公共 HTTPS，所需身份是普通教师而非运维，服务级崩溃超出授权效果，正常识别判分也满足已判分条件。概念验证采用 128 MiB 堆，没有完成原生 OCR 全链，但一亿对象同样超出现实默认堆容量，认证开启的真实 HTTP 入口及崩溃位置均已执行。

## 发生可能性

高。文档支持远程 HTTPS，使用普通教师权限及正常 JSON 改卡、判分和总览流程，没有竞争、秘密提取、原生漏洞或用户交互要求。已判分学生是正常状态，验证证明认证接收、持久化、内存耗尽及重启后再次触发。教师凭据和授权考试要求使范围比匿名情形更受限，但对威胁模型中的恶意或失陷教师仍为高。攻击向量为远程网络。

## 影响程度

/** 按 10 分一段动态生成分数段，末段截止于满分 */
function generateDistributionRanges(fullScore: number): Array<{ range: string; min: number; max: number }> {
  const step = 10;
  const ranges: Array<{ range: string; min: number; max: number }> = [];
  for (let min = 0; min < fullScore; min += step) {
    const max = Math.min(min + step - 1, fullScore);
    ranges.push({ range: `${min}-${max}`, min, max });
  }
  return ranges;
~~~~

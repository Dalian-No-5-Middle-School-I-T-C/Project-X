# 11 试卷转换失败遗留近50MB临时上传文件

- 原标题：Failed paper conversions leak 50 MB temporary uploads
- 云端级别：High
- 原始报告：[打开报告](https://chatgpt.com/codex/cloud/security/findings/249c894561c08191a8427dde9773ea90?repo=https%3A%2F%2Fgithub.com%2FDalian-No-5-Middle-School-I-T-C%2FProject-X&sev=)
- 关联提交：[0439c2a](https://github.com/Dalian-No-5-Middle-School-I-T-C/Project-X/commit/0439c2a7625be88e492b15c6eaca3f90ac9e17a7)

## 概要

本提交新增试卷上传转换，却仅在成功后删除临时文件。Multer 先把最多 50 MB 文件写入 papers/_tmp，校验只相信扩展名和大小。任意畸形内容命名为 .jpg 即进入 Sharp；metadata 或转换抛异常后，storePaperFile 失败，catch 返回 500 却不删除 req.file.path。每次生成新临时文件，又没有该目录清理，默认 grade:write 教师可以每请求持续增加近 50 MiB，最终影响共享卷上的上传、扫描、阅卷、数据库和日志。

原报告建议把全部上传后处理包在 finally 清理内，并在 Sharp 等解析前校验魔数。

## 验证及证据

HTTP 验证覆盖原样门禁、路由、Multer、Sharp 和文件系统：匿名请求 401；已认证 52428799 字节畸形 JPG 与 1 MiB 文件均返回 500，遗留完整、哈希一致的独立文件，总计 53481472 字节。恰好 50 MiB 是对照边界：Multer 拒绝且删除部分文件。接口未添加更严格卡片所有权或存在性检查。定时清理只处理数据库关联扫描记录，不覆盖 papers/_tmp。

代码证据是扩展名／大小过滤、Sharp 可失败解析、磁盘临时存储，以及 storePaperFile 成功后才 unlink 的控制流。

## 攻击路径与分级

普通教师 multipart 上传扩展名合法的畸形图像 → Multer 写临时文件 → Sharp 抛异常 → 500 分支遗漏 unlink → 每次独立文件累积 → 有限共享磁盘耗尽。

发生可能性高：正常网络上传，无竞态或精巧解析漏洞；仓库 Nginx 示例通过 80/443 公开回环 5174。影响程度高：每次近 50 MiB 永久累积，可妨碍其他用户考试业务；数据库影响取决于是否共卷。不是自身影响或需要主机权限的路径；需普通教师、重复请求且限一个服务／文件系统，未证明窃密、改分、RCE 或系统接管，所以高危。

## 假设条件与已有控制

采用威胁模型的生产认证开启假设，而非依赖该历史版本未认证兼容默认；普通教师保留 grade:write；支持的公开 Nginx 入口可达；有限存储没有外部配额或仓库外陈旧文件清理；允许重复上传。

认证开启时要求权限；Multer 名义单文件上限 50 MiB；扩展名允许列表；成功路径尝试清理；safeId 清理卡片目录标识，避免目录穿越。已有扫描清理不处理试卷临时目录；无累计配额、按主体上传限速或临时文件过期清理。回环绑定在已配置反代时不能隔离网络攻击者。

## 盲点

完整服务因缺 expr-eval 无法启动，真实令牌验证仅静态确立，门禁及上传／转换链动态执行。真实磁盘、告警、容器和反代限额未知。.codex-deploy-tmp 中的 Nginx/systemd 示例不代表每个实例。SQLite 或远程 MariaDB 是否共用被填满的卷影响连带范围。人工删除可恢复但不能自动防复发；未实际填满磁盘。

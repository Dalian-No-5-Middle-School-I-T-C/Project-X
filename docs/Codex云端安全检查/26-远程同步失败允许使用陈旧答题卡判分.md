# 26 远程同步失败允许使用陈旧答题卡判分

- 原标题：Remote sync failure permits grading with stale card data
- 云端级别：Medium
- 原始报告：[打开报告](https://chatgpt.com/codex/cloud/security/findings/b1eaf2a22084819191b7d7e4e4829617?repo=https%3A%2F%2Fgithub.com%2FDalian-No-5-Middle-School-I-T-C%2FProject-X&sev=&page=2)
- 关联提交：[afb50c9](https://github.com/Dalian-No-5-Middle-School-I-T-C/Project-X/commit/afb50c9a5b3ccec0ff147d5263048db16e26443c)

## 概要

新同步路径在远程配置下对网络错误、超时、5xx、甚至成功响应的非法 JSON 静默回退本地；401/403/404 则关闭式失败。fetchSynced 虽返回来源，fetchCardByIdSynced 将其丢弃，ScannerApp 无法区分权威远程卡与缓存，直接导入本地并进入工作区，随后本地 /api/cards/:cardId/grading 使用旧布局和答案。

学校服务器已更改或删除卡片，而扫描端保留同 ID 旧副本时，邻接／在途攻击者只需选择时阻断详情连接。HTTPS 防窃听篡改，不防丢包。列表若刚从远程获取，页脚还可能显示同步成功；没有逐卡陈旧提示、版本确认或阻止判分。建议远程模式详情失败时拒绝继续，或强制校验版本／校验和；离线使用应确认缓存版本，上传绑定版本让服务端拒绝错配。

## 验证及证据

真实同步、导入和判分模块及既有 smoke 测试确认网络失败、500、坏 JSON 回退，401/403/404 不回退；同 ID 旧卡被导入并用于判分，旧答案得到 10 分，权威答案应为 0。详情来源丢失，列表状态未因详情回退变化。

## 攻击路径与分级

无账号的邻接／在途攻击者丢弃详情连接 → broad catch → 旧本地卡 → 丢来源且 upsert → 工作区本地识别判分 → 错误但看似合理的显示／CSV 成绩。

影响程度高：布局、答案、题分、总分及批处理可受影响。发生可能性中：需在途位置、同 ID 缓存分歧、远程修改／删除、合适时机及操作员选择判分。操作员点击是受害者交互，不等于攻击者拥有运维权限，非仅自身。按高影响×中可能性为中危。

## 假设与控制

远程扫描配置和有效 scanner/full 密钥，嵌入库有旧卡，攻击者能中断详情，操作员在恢复／发现前继续。高影响假设显示或 CSV 被学校实际采用，未证明错误分直接写入中心权威库。

远程同步有 API 密钥／非学生 JWT；401/403 和权威 404 不回退，404 留在选择页刷新；列表可显示离线缓存，另有健康轮询；Electron 隔离、沙箱、禁 Node、回环服务；X-Api-Key 服务端哈希匹配，客户端 localStorage 30 天。健康可滞后或在选择性失败时正常；没有详情来源强制、不可变版本或上传版本绑定。

## 盲点

测试模拟传输边界，未对打包 Electron 真丢包或运行原生 OCR。未知公网／VPN／校园网入口、缓存分歧频率和操作员察觉概率。背景上传只带图像/cardId，没有版本；未证明后续中心处理会纠正、拒绝、重复或持久化旧分。因此只确认本地显示及可导出错误，不能扩大为中心库已改错。

# 17 学生AI端点允许无限计费模型请求

- 原标题：Student AI endpoint allows unbounded billable LLM requests
- 云端级别：High
- 原始报告：[打开报告](https://chatgpt.com/codex/cloud/security/findings/58123da473708191aeda992e2b1c0021?repo=https%3A%2F%2Fgithub.com%2FDalian-No-5-Middle-School-I-T-C%2FProject-X&sev=)
- 关联提交：[aef25aa](https://github.com/Dalian-No-5-Middle-School-I-T-C/Project-X/commit/aef25aa642c17ea910bd7f62ad1fc25110036b35)

## 概要

本提交首次在学生成绩路由增加可触发外部模型的 POST /api/scores/me/exams/:examId/ai-analysis。仅校验普通认证及学生在该考试有成绩，之后每次请求都新建最长 120 秒的 /analysis/run 调用，接受任意已配置模型，无频率、配额、缓存、请求合并、冷却或在途并发上限。辅助服务每次分析可最多调用提供商 8 轮，每轮 max_tokens=4096。UI generating 标志不能防直接调用，内部 Bearer 密钥也不能在可信 Node 转发时提供逐学生限制。

此精确版本还有配置命名错配：路由读 LLM_CLIENT_URL／LLM_INTERNAL_KEY，既有集成用 LLMCLIENT_URL／LLMCLIENT_INTERNAL_API_KEY。正确设置非空内部密钥时此路由可能 401；但文档允许内部密钥为空，此时接受请求，单修配置错配也会激活同样无上限链。建议服务端用户／IP 配额、全局并发上限、去重缓存及显式授权和成本核算。

## 验证及证据

真实 auth/scores HTTP 路由连接不计费的模拟辅助服务：合格学生 12 个并发请求全部成功，产生 12 个同时在途调用，传递 gpt-5.5-pro；匿名／无成绩对照为 401／403。真实 provider 循环替换网络客户端后产生 8 次、每次上限 4096 的调用。真实 FastAPI 证明空密钥接受、非空且无 Bearer 时拒绝，源码确认命名错配。

## 攻击路径与分级

有一条成绩的学生 → 无限制串行／并发 POST → 可复用 hasScore → 每次独立 120 秒转发及模型选择 → 学校提供商凭据驱动最多 8 次调用 → 费用／配额及 Node 请求、辅助服务线程耗尽。

发生可能性高：正常低权限身份、简单 HTTP，无竞态、枚举或受害者交互；空密钥是受支持状态。影响程度高：学校共享成本及 AI 可用性，而不是仅攻击者自己等待。需可用集成，非全实例接管、代码执行、泄密或改分，故高危。

## 假设、控制与盲点

学校服务可达；学生会话和选定考试成绩存在；Python 服务有模型及可用提供商密钥；内部鉴权接受路由（空密钥或配置已对齐）；提供商按量计费或额度有限。

有效身份、hasScore、已知模型及密钥检查、单请求 120 秒超时、可选内部密钥、UI 单次生成禁用及回环绑定都是现有控制，但不限制累计调用和并发。正确非空 LLMCLIENT_INTERNAL_API_KEY 且未修命名时会阻断此精确版本路径。

未联系真实模型、计费或制造持续停机；8 轮是重复工具调用可达上限，不是每次平均值。提供商价格／额度／限速、连接上限、线程数及反代限制未知。完整生产 index 因缺依赖未动态加载，挂载顺序静态核对，原认证与成绩路由动态执行。可选 AI 和公网入口并非每实例都有。

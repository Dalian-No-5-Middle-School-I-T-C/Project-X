# 02 登录页指南暴露初始化管理员凭据

- 原标题：Login-page guide exposes bootstrap administrator credentials
- 云端级别：Critical
- 原始报告：[打开报告](https://chatgpt.com/codex/cloud/security/findings/134ccdfba8288191aae2a064c13c55f8?repo=https%3A%2F%2Fgithub.com%2FDalian-No-5-Middle-School-I-T-C%2FProject-X&sev=)
- 关联提交：[535ccbe](https://github.com/Dalian-No-5-Middle-School-I-T-C/Project-X/commit/535ccbe86fddb40c815a85bd78bfc42c7b08f807)

## 概要

本提交新增未认证 LoginPage 的使用指南入口，并把包含真实初始化凭据的完整 Markdown 指南打包进公开客户端。App 在未登录时渲染 LoginPage，新按钮无须授权即可打开 UserGuideModal；UserGuidePage 静态导入并显示明确写有 admin/admin123 的指南。后端恰好创建同样的活跃管理员账号，登录后获得通配符权限。

攻击者可访问公开的新建／恢复实例，从登录页或 JavaScript 包直接读到凭据，在合法运维人员改密前登录并自行改密，从而访问学生记录、试卷、备份、凭据和成绩操作。已改过密码的实例不受影响。固定凭据早于本提交已存在；本次新问题是把它直接发布到部署实例的未认证界面。原报告建议不要在登录前暴露凭据，初始化改用每实例随机一次性密码或本地激活机制。

## 验证

云端通过源码、提交 diff、成功的 Vite 构建及未认证 HTTP 获取的构建资源，确认指南与凭据公开；全新数据库确实创建无需激活的活跃管理员。真实 /api/auth/login 返回 200、令牌、管理员身份和通配符权限；该令牌能访问受保护的 /api/users，攻击者改密后能以新密码登录。提交 diff 证明新增的是未认证 UI 暴露。

## 证据说明

LoginPage 的前置指南按钮无授权检查；UserGuidePage 将原始 Markdown 内容放入公开资源和模态框；指南发布固定用户名和密码；数据库创建同样的活跃账号；登录服务返回有效令牌及权限；管理员角色拥有通配符权限。

## 攻击路径与分级

匿名访问公开登录页 → 打开指南或下载公开 JS → 获得固定凭据 → POST /api/auth/login → 活跃管理员会话 → 受保护管理及教育数据操作。

PoC 完成凭据披露、登录、受保护端点访问与改密，无需猜测额外利用链。startServer 监听 127.0.0.1、固定凭据此前已在仓库、只影响首次改密前窗口，这些限制不能阻断 deploy-guide.md 所支持的公网 HTTPS Nginx 部署。对应历史提交没有先行激活或强制改密状态阻止首次特权会话。若存在强制改密流程，攻击者也能抢先完成。

发生可能性高：受影响实例上可确定性利用，无既有账号或受害者交互。影响程度高：获得全实例管理员身份并可替换密码，影响账号、考试、成绩、备份和配置，可能造成破坏性停机。影响不限于自身，也非运维／开发／物理访问专属问题；按原报告矩阵归为严重。

## 假设条件

客户端和 API 对应关联提交；新建或恢复数据库的固定密码尚有效；可通过文档支持的 HTTPS 反代或等效入口访问；攻击者先于合法管理员完成登录及改密。

## 已有控制

Node 默认回环监听；bcrypt 密码验证和通用失败提示；受保护路由执行身份及角色／权限校验，拒绝匿名用户管理请求；随机不透明会话和 HttpOnly、SameSite=Lax Cookie；改密撤销旧会话；指南要求立即修改默认密码。持有当前有效初始化密码的攻击者可以通过这些校验，因此上述控制不阻止此路径。

## 盲点

未确认任何特定生产实例实际公开。验证时 node_modules 缺少已声明依赖，无法启动完整 createApp；可执行测试改用仓库生产初始化器、认证服务、中间件、路由、已构建客户端及回环 HTTP 服务器。没有逐一执行判分、备份、删除或配置操作。该提交并非固定凭据的首次引入，只是首次通过未认证产品界面和公开资源分发。真实利用窗口随管理员改密结束，仓库无法确定各实例的改密速度。

# 28 演示导入安装公开的全校教师凭据

- 原标题：Demo import installs documented school-wide teacher credentials
- 云端级别：Medium
- 原始报告：[打开报告](https://chatgpt.com/codex/cloud/security/findings/dc1ff6aaf29c81919f8cb436769fb268?repo=https%3A%2F%2Fgithub.com%2FDalian-No-5-Middle-School-I-T-C%2FProject-X&sev=&page=2)
- 关联提交：[57bc7c4](https://github.com/Dalian-No-5-Middle-School-I-T-C/Project-X/commit/57bc7c421c714fb0a5db85fd6345abc2e95f38cf)

## 概要

本提交把原开发者测试 seed 变为生产 DemoDataService、管理员 API 和 Web 操作。在 SQLite 正常界面导入 demo-teacher／demo-teacher-2，固定 teacher123；缺 teacher_role 与 password_change_required，默认活跃、普通教师、无需改密。API 响应与 README 公开凭据；null 子角色在 getVisibleExamIds 代表所有考试，默认教师有卡片／考试／成绩写权限，未限制演示数据。

因此管理员看似导入样例后，匿名远程攻击者可登录读取全校记录，修改成绩／答案或删除真实考试。建议随机一次性密码并改密、严格限定演示班级／考试，或仅隔离演示模式允许这些账号登录。

## 验证及证据

真实 API 导入 200，数据库与登录确认 active、teacher_role=null、passwordChangeRequired=false；真实 GET/PATCH/DELETE 成功访问、修改、删除管理员所有的非演示考试。成绩和答案写入只按可达源码追踪，未另行执行。UI 将操作描述为不覆盖现有数据的演示导入，没有说明会启用公开高权限凭据。

## 攻击路径与分级

管理员 SQLite 导入 → 固定密码账号 → 攻击者登录 → 普通教师令牌 → null 范围被解释为所有考试 → 真实考试及成绩操作。

影响程度高：从匿名到非演示学校记录读写，可能影响保密性、完整性和可用性，但非管理员或跨实例接管。原可能性字段标 High 后在解释中因管理员主动操作、SQLite 限制、开发模式入口、可清理、回环绑定和部署差异调整为中，最终为中危。管理员导样例并未授权陌生人持其教师身份，不属于只能由特权攻击者利用的排除情形。

## 假设与已有控制

仅 SQLite（此版本 MariaDB 拒绝）；管理员有 USER_MANAGE＋SYSTEM_MANAGE 并操作；账号未清理、改密、禁用；默认教师范围／权限未收紧；反代入口可达。

导入认证与双管理权限、开发高风险菜单、确认框、bcrypt、每 IP 15 分钟 10 次登录限制、随机会话与 HttpOnly/SameSite=Lax、强制改密中间件及 requireExamAccess 都存在，但默认标志和 null 兼容范围使后两者不起限制作用。管理员 clear-demo 可删除样例，回环监听需外部代理才能远程。

## 盲点

真实公开状态、角色自定义、导入频率和账号保留时间未知。动态证明登录及非演示考试读写删除，没有单独执行改分／答案。部署指南虽提 HOST 设置，但该提交 startServer 显式回环绑定，远程仍依赖代理。未知运维是否另行改密、禁用或防火墙限制。

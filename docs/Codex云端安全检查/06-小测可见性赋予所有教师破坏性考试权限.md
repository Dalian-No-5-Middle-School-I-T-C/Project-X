# 06 小测可见性赋予所有教师破坏性考试权限

- 原标题：Quiz visibility grants every teacher destructive exam access
- 云端级别：High
- 原始报告：[打开报告](https://chatgpt.com/codex/cloud/security/findings/fb904f4d89b08191b6a0236883c663f6?repo=https%3A%2F%2Fgithub.com%2FDalian-No-5-Middle-School-I-T-C%2FProject-X&sev=)
- 关联提交：[7ef4296](https://github.com/Dalian-No-5-Middle-School-I-T-C/Project-X/commit/7ef4296e7cbea2e2eb5d8129f5f9120f76c7ea8d)

## 概要

本提交把所有 exam_mode='quiz' 考试加入每名受限教师的 getVisibleExamIds，未区分读取可见性与编辑、判分、模式管理和删除权限。requireExamAccess 对所有 HTTP 方法复用可见性集合，因此现有破坏性路由立即继承扩大后的范围。

默认教师同时具有考试和阅卷写权限。与某小测无班级、学科或所有权关系的学科教师／班主任，可从考试列表枚举该考试，调用 PUT /api/exams/:examId/student/:studentId/scores、PUT /api/exams/:examId/answers 或 DELETE /api/exams/:examId。答案接口改写关联答题卡并自动重算全体客观题成绩；删除接口移除逐题分、总分、扫描批次及考试。新模式更新接口也仅用 requireExamAccess，虽然客户端仅向管理员显示模式切换。教师可把可访问正式考试改成小测扩大其暴露，或把任意小测改成正式考试。允许读取小测未必是漏洞，但将读取范围直接当作破坏性写入范围会越过班级、学科和阅卷边界。

## 验证及证据

普通受限教师登录后获得无关小测 ID；通用功能权限与对象门禁不区分读写。云端使用真实 Express／认证路由及 verify:176-178 测试框架，断言全部通过，确认跨学科改分、改模式、删除无关小测及其分数／扫描批次记录；同等无关正式考试删除返回 403。

代码证据包括 withQuizExamIds 无条件并入全部小测、方法无关的 requireExamAccess、仅依赖该门禁的分数与答案接口、无所有权／班级／学科／管理员检查的删除接口，以及仅前端限制管理员的模式控制。

## 攻击路径与分级

已认证数学教师 → GET /api/exams 得到他人历史学科小测 → exam:write 默认权限通过 → requireExamAccess 把可见性视为写授权 → 改分／改答案／改模式／删除 → 跨范围成绩、排名、答案、批次及考试数据遭修改或删除。

发生可能性高：正常 HTTP、可枚举 ID、默认教师权限，无竞态、管理员、主机 Shell 或秘密提取前提。影响程度高：他人的权威教育记录可被篡改或删除，答案修改还可触发全考生重算。原报告排除“仅自身”或“仅管理员”降级，因受保护写入口本身的对象校验失效。需教师账号，主要限于单实例小测集合，未证明匿名接管、RCE 或整个实例失陷，因此为高危。

## 假设条件和已有控制

默认认证未关闭；攻击者是活跃学科教师或班主任，无受害考试所有权、对应班级／学科或管理员身份；目标为 quiz；角色保留默认 exam:write；知道考试／学生 ID，小测 ID 可由列表取得；支持的学校 Web／HTTPS Nginx 入口可达。

认证使用不透明令牌或 HttpOnly、SameSite=Lax Cookie；该历史版本登录每 IP 每 15 分钟限 10 次；/api/exams 写方法检查 exam:write；正式考试仍执行范围限制；请求体有结构校验；改分／改答案使用事务，记录 modified_by 或 answer_overrides 并重算排名。自定义角色可去掉写权限，但默认角色具有它；前端隐藏模式开关不是后端授权。

## 盲点

真实部署可能仅本地／学校内网，角色也可能被收紧。仓库注释、schema 和提交说明确有“小测全局可见／完整权限”措辞，因此政策意图存在歧义；原报告认为这与提供的威胁模型及仅管理员模式 UI 不一致，不能据此认可全部破坏操作。动态验证使用 SQLite，MariaDB 未运行，但授权组合与数据库无关。直接验证了改分、模式和删除；答案引发全考试重算由可达源码证明，未另行执行。

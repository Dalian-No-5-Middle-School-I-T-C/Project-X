## 柯达 i3000 扫描仪接入

### 新增文件
- `scripts/scanner/kodak_scan.py` — Python WIA 扫描控制脚本，支持 list/status/scan 三个子命令。通过 Windows WIA COM 接口连接扫描仪，支持 DPI、色彩模式、ADF 双面扫描等参数配置，输出 JSON 到 stdout 供 Node.js 侧解析。

### 修改文件
- `src/apps/answer-card/server/scanner.ts`：
  - 新增 `KodakScannerDriver` 类实现 `ScannerDriver` 接口
  - 新增 `getActiveDriver()` 工厂函数，根据 `scanner_driver` 配置返回对应驱动
  - `KodakScannerDriver.scan()` 流程：spawn Python 子进程 → Python 执行 WIA 扫描 → 返回文件列表 → 逐文件走 `processFile()` 入库 → 清理临时文件
  - `KodakScannerDriver.getStatus()` 调用 Python 查询设备连接状态
  - `KodakScannerDriver.cancel()` 通过 `taskkill /T /F` 杀进程树
  - 新增 `python_path` 配置项支持和自动检测

- `src/apps/answer-card/server/index.ts`：
  - 引入 `KodakScannerDriver` 和 `getActiveDriver`
  - `/api/scanner/status` 现在返回真实设备状态（device 字段）
  - 新增 `POST /api/scanner/scan` 端点（柯达直连扫描入口）
  - 新增 `POST /api/scanner/scan/cancel` 端点（取消扫描）

- `src/apps/answer-card/client/ScanPanel.tsx`：
  - `ScanConfig` 接口新增 `device?: DeviceStatus` 字段
  - 启用 `kodak_sdk` 驱动选项（不再 disabled）
  - 新增柯达扫描控制面板：DPI/色彩模式/双面开关 + 扫描/取消按钮
  - 工具栏显示扫描仪连接状态
  - 新增 `handleKodakScan()` / `handleKodakCancel()` 函数

- `src/apps/answer-card/client/styles.css`：
